# 发布与演示指南

当前为候选ver1.0，已具备本地运行和静态构建，**未上线公开试用地址**。私有GitHub仓库是源代码托管，不等同于题目要求的普通用户互联网直接试用。

## 构建与发行文件

在仓库根目录执行：

```powershell
node savior/tests/run.cjs
node savior/scripts/build.cjs
```

生成 `savior/dist/`，内含 `index.html`、`src/` 中4个资源文件和 `SHA256SUMS.txt`。部署时保持相对路径完整，以dist为网站根目录，不需要运行Node业务后端。

如需本地下载包，可在PowerShell使用：

```powershell
Compress-Archive -Path savior/dist/* -DestinationPath savior/小芽口算-ver1.0.zip
```

发布包只含公开应用，不应包含课程原始材料、真实儿童数据或本机备份。生成的发行目录可再构建，不是源代码副本的替代。

## 正式发布门槛

1. 完成手动验收，尤其键盘、计时、备份和打印。
2. 小组确认选题，与老师明确发布与代码管理渠道。教案指定Gitee及Wiki流程，现有GitHub私有仓库不能默认替代。
3. 选择可用静态托管平台，发布dist目录。平台当前可用性和权限应在实际部署时确认，不假定教案提及的历史服务仍可直接使用。
4. 发布介绍页应包含软件说明、实际截图、使用方式、试用入口及下载方式。本仓库README提供介绍文本；截图需人工验收后补齐。
5. 从另一台设备和非开发者账户验证打开、生成、批改、历史和备份，无需注册。
6. 记录正式URL、发布日期、版本、外部验证结果，介绍页面至少保留一个月。

## 8分钟课堂演示建议

| 时间 | 内容 |
| --- | --- |
| 0:00–1:00 | 题目情境、NABCD和真实调研证据；未完成调研则明确说明 |
| 1:00–2:00 | 范围、预设和数学规则 |
| 2:00–3:30 | 5题演示：Tab输入、计时暂停、Enter批改和表现说明 |
| 3:30–4:30 | 错题原题与变式，掌握状态 |
| 4:30–5:30 | 历史与题型统计、备份恢复 |
| 5:30–6:30 | 打印预览和离线运行 |
| 6:30–7:30 | 架构、关键算法、测试和版本管理 |
| 7:30–8:00 | 实际反馈、局限、下一步 |

使用演示数据时标明演示，不伪装成实际儿童学习记录。正式答辩前保留本地副本，避免网络影响演示。
