# 灵梦自机弹体

三款均已获用户人工验收通过。原图对照取自 PROJECTILE_CATALOG 的 player00 ANM 64/65/66；符纹为重新绘制的三维适配，并非原精灵直接贴到平面。请重点验收符纹还原程度。

每个目录包含可编辑 blend、标准 glTF/bin、collision.bin、asset.json、REVIEW.md。符札宽高 1、厚度 0.07，侧边有倒角；针长 2.2。+Y 朝前，正面 +Z，原点位于中心。贴图正反面独立 UV，侧面采样纯色区。glTF 为普通 raylib LoadModel 可加载资源，不需要敌弹的角色编码着色器。

运行 tools/windows/Review-Reimu.cmd。Tab 切换，V 三款同屏，鼠标拖动旋转、滚轮缩放；1 灰模、2 实体、3 成品；4 在碰撞叠加/仅碰撞/成品之间循环；G 光效、B 背景、A 游戏 Alpha 51 预览。方向键移动探针 XY，PageUp/Down 移动 Z，红色接触、绿色为空。F12 保存截图。

符札光效采用独立放大加色层；针弹光效单独保存为 glow.gltf/glow.bin，是 288 面的开口圆锥侧面，尖端 Y=1.1、尾端 Y=-1.1、尾半径 0.24。颜色和强度可在审阅器的 DrawModel 参数调整；这是模型外部效果接口，不写入碰撞。游戏 Alpha 预览仅展示额外 Alpha 51 的影响，不声称复现完整 ANM 透明度乘积。针弹圆锥光效由 reimu_cone 着色器提供轴向渐隐，双面加色显示，保留深度测试并关闭深度写入。接入时主体按普通 glTF 加载，圆锥使用配套着色器与透明绘制状态。

碰撞为主体同源封闭三角网格，KCOL0001 格式，可通过现有 CollisionAsset 读取；含符札倒角、针尖和尾端，排除光效。游戏目前球形判定未更改，接入时须显式采用新碰撞资源。

统一检查命令：项目内 Python -I tools/projectile_review/verify_reimu.py 项目根目录。检查有限坐标、非退化三角形、封闭边、正体积、文件引用及预算。全组完成后已检查，并生成 output/projectile-review/reimu 下 24 张截图。不运行任何性能测试。

纹理修订：外围纹样按用户根目录 `草图.png` 重绘为左右长弧框、四角短钩和两侧横划，与底色一起以像素间中心 (255.5,255.5) 旋转 180° 重合；中央文字独立绘制，仅一枚正立“博”，不参与旋转对称。圆锥光效提高亮度和透明度，并延后尾部渐隐以增强轮廓。面数与碰撞数据不变。

外围纹样已摆正：横竖段分别对齐坐标轴，圆角切线水平或竖直，左右和上下间距一致；主线宽 12 像素，短竖线 10 像素（512×512 贴图）。文字保留单枚正立“博”。
