# 新典战斗尺寸

本项目以本机《东方红魔乡：新典》为尺寸来源。EXE SHA-256 为 `48630a42a2eb6762d0db2a7e0d151203efbe67220fef7d2f9d0d51857928ac82`；ANM 保持原包字节，逐文件哈希见 `assets/runtime/battle/native/checksums.sha256`。敌人判定读取各关 ECL 的 103 指令，输入身份沿用 [逐关记录](STAGES_2_6_REFERENCE.md)。

## 统一比例与显示几何

战斗尺寸统一采用 **20/448 世界单位/原作逻辑像素**，与既有敌人路线的长度比例一致。`native_sizes.hpp` 保存公共比例与已审阅的世界判定常量；生产时间轴、命名行为继续保存世界值，不从 ECL 构造运行时事件。

ANM 精灵记录是 28 字节 `<I6f>`：编号、裁切 X/Y/宽/高、显示宽/高。两个显示维度分别优先使用记录中的非零值；零值才按裁切尺寸乘 `480/1080` 补齐（原加载器 RVA `0x28c9–0x2a8e`）。裁切矩形只决定 UV，不能代替显示几何。`Sprite::displaySize` 和 `Frame::LogicalSize()` 保留这个区别，几何再叠加 ANM 缩放、旋转和局部偏移。DDS 的高清分辨率不参与世界尺寸。

所有加载的原生战斗外观由 `AssetManager` 应用公共比例，首张精灵的基准高度只用于传递入退场/副机的额外缩放；当前精灵变小时，实际世界几何也随之变化。演员、弹幕、道具和退场快照的透明排序与绘制共用同一组顶点。旧 PNG 外观继续读取自己的 `worldHeight` / `bulletDiameterScale`；原生清单已删除这些旧人工倍率。

下表均为原作逻辑像素，显示尺寸是未叠加动画的全宽高，判定为新典圆形半径（模板初始化 RVA `0x12979–0x12a3a`）。三维沿用球形判定。

全部 118 个有效弹种/颜色组合及火球四帧均核对。大泡 C4 是原包较小的精灵，判定仍继承 9 号模板，不因颜色变为 30 的直径。`EnemyBulletLogicalSize(type,color)` 用于行为几何（包括反弹半尺寸），`EnemyBulletHitRadius(type)` 用于碰撞，显示不再通过判定半径乘一个统一倍率得到。

敌方激光全宽、长度继续由各攻击的世界参数控制。魔理沙激光判定使用火力表的全宽 10/15/20 和长度 480；显示全宽独立采用 ANM 精灵逻辑宽乘脚本缩放，移除额外的 1.5 倍。两者仍各自受展开/淡出时窗控制。

## 敌人与 Boss

普通演员 ECL 全宽多为 28×28，二面部分精灵为 16×16 或 22×22，对应世界半径 0.625、0.357142857、0.491071429；既有生产出生配置已符合这些原值，保留原事件时序和参数。默认未设置的原生敌机全宽为 12。

Boss 按 ECL X/Y 全宽的较短边除二，转为三维内接球；源 Z=32 不作为三维球直径。受弹、追踪与 Bomb 共用该球，本体接触另乘原生 `2/3` 比例。显示尺寸独立读取当前动画，不用判定半径推断。

## 自机、道具与 Bomb

自机命中半径采用 EXE RVA `0x69a24` 的 1.25 逻辑像素，世界半径约 0.055803571；擦弹在该半径外增加 20 像素。普通自机弹将火力表矩形的短边除二转为三维球，当前四机体各档短边均为 12 像素，半径约 0.267857143。针的原生 12×40 判定保留在目录，三维仍是内接球，不宣称复现完整二维矩形。

两角色副机原始裁图为 36×36，显示直径为 **16**，世界高度约 0.714285714。第一视角模块锚点和通道局部偏移保留既有布局比例 `0.42/36`，与原生显示/判定尺寸分离，避免尺寸迁移改变出射位置；三维汇聚、Focus 时长与近目标模块缩小保持原语义。自机弹显示分别采用 ANM：灵梦符札 14×14、侧针 14×46；魔理沙主弹 16×32、导弹 16×16，爆破基准 32×32 后叠加原生缩放。导弹爆破判定全宽仍为 32/42/48 像素。

道具基础显示为 16×16，再叠加自身脚本缩放。球形拾取距离按道具半宽 8 与自机原生拾取半宽 12 合成 20 像素，约 0.892857143 世界单位。

Bomb 保留已有三维布局、伤害通道、数量与时序；原生攻击半径/厚度、运动和清弹容差改用同一 `20/448` 比例。梦想封印的显示基准为 62 像素，星群按自身 ANM 基础显示尺寸而不是固定 3.6 世界单位绘制。三维法阵与 Master Spark 的场地覆盖仍由攻击实体决定。64 颗网格星的原生 64 像素攻击半径现在是 `20/7` 世界单位；到达格心后的联合覆盖约 64.94%，128³ 完整小盒计数下界为 **57.9834%**。旧 `20/384` 比例下的 80% 覆盖指标已随尺寸迁移废止，不放大原作半径维持旧指标。

## 复现与回归

```bash
python3 tools/inspect_native_sizes.py /本机新典/th06nc.exe /已解包ECL目录 --output /tmp/native-sizes.json
cmake --build build/macos-debug --target koumakyou koumakyou_tests koumakyou_postgame_tests -j 6
ctest --test-dir build/macos-debug --output-on-failure
cmake --build build/macos-debug --target koumakyou_lifecycle_tests koumakyou_sprite_overlap_tests native_asset_preview -j 6
./build/macos-debug/koumakyou_lifecycle_tests /tmp/native-size-lifecycle
./build/macos-debug/koumakyou_sprite_overlap_tests /tmp/native-size-overlap build/macos-debug/assets
```

只读审阅器记录 25 份 ANM 的全部精灵与七关 ECL 判定设置、输入哈希、偏移和 EXE 尺寸常量；临时报告不进入生产。测试独立冻结原包显示/判定常量，覆盖所有颜色、Boss 遭遇和咲夜开战交接、实际公告板顶点、高清裁切不改变几何、非法显示尺寸、60/120 Hz 与多显示帧率。旧解释器继续保留旧项目两档弹半径，轨迹差分与本次新典尺寸修正分别验收。

2026-10-27 在 macOS Debug 完成构建与全部 3 项 CTest；完整图形生命周期（含整关、Boss 退场、多帧率轨迹）、GPU 透明遮挡、四 Bomb 的伤害/清弹/绘制/暂停及全部 25 图集、347 脚本的 0/12/32 帧预览均通过。旧行为差分最大累计世界位置误差仍为约 `1.92642e-4`，未扩大容差。
