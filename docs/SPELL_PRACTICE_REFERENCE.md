# Spell Practice 新典对照

本次通过本机 `output/th06nc-reference.app` 实际操作核对 Spell Practice，并读取同一安装版本的 `th06IN.dat` 与 `th06TL.dat`。实现使用本项目的页底、边框、衬线字体、选择强调、响应式画布与页面过渡；不依赖原游戏运行或临时解包目录。

## 核心流程

首页 Spell Practice → 关卡选择 → 同页符卡与难度选择 → 加载并开始练习。键盘先用上下键或 W/S 选择符卡，Z／Space 确认后操作右栏难度；返回先将焦点交回符卡栏，再返回关卡页。两栏始终显示，焦点递进和返回不更换页面、不重新播放整页进场。难度确认后直接加载，不经过普通 Start 的准备横幅，退回首页时仍选中 Spell Practice。

鼠标悬停符卡时立即强调该项并联动右栏内容，无需点击即可直接移入难度栏选择，左键确认难度；也可从右栏直接悬停左栏的另一张符卡。不存在的难度空槽不接管焦点或启动，未解锁及未实现的变体可悬停浏览但不能启动。静止指针不覆盖键盘选择和返回。左右键或 A/D 始终循环切换灵、梦、魔、恋；人物左右箭头点击只切换组合，不能同时确认列表。符卡组超出八行时可继续上下导航、在对应栏目滚轮浏览或点击上一页／下一页。两个栏目独立保存选中强调，当前操作栏目以较强亮度显示。

关卡和符卡组中的灰色项仍能展开浏览原文，难度中的灰色变体不能启动。原典不存在的难度显示 `------`，也不能跳到其他符卡。当前灵／梦／魔／恋四种御札均接通第一面 Normal 的 No.003 夜符「Night Bird」和 No.007 暗符「Demarcation」，但新存档须先以当前组合在实际关卡内遇见才可练习；难度卡片分别标注“已解锁／未解锁／尚未实现”。魔理沙使用独立 player01 的主副弹和星形副机，不借用灵梦机体。御札射击实现见 [魔理沙御札对照](MARISA_SHOTS_REFERENCE.md)。

结算保留“返回符卡选择画面／保存Replay／重试”，默认重试；项目尚未实现 Replay，保留该项并置灰，键鼠跳过。Success／Failed 与暂停共用圆角浮窗、居中文字、选中金色下划线和过渡效果；标题下独立保留分数及 Graze／Miss／Bomb 统计区，绘制与鼠标命中使用同一布局。成功捕获显示 Success，受击、Bomb、超时或失败不能记为捕获。暂停另有返回符卡选择，结束或返回后保留关卡、符卡组、难度和组合，释放战斗资源并显示光标。

## 完整目录

`src/app/spell_practice.cpp` 保存从 `spellpractice.msgpack` 的 `entries` 与 `localization.msgpack` 的 `zh-CN` 项提取的只读目录。原始条目为 `[编号, 关卡, 脚本编号, 难度, 关内符卡组, 道中标记, 本地化键]`；源码的编号为原始编号加一，难度 0～4 对应 Easy、Normal、Hard、Lunatic、Extra。符卡组按原典归并，不按名称猜测：同组的不同难度可以有不同名称。

六面道中奇术的使用者为咲夜，Extra 前三组的使用者为帕秋莉，不能直接套用该关关底 Boss。关卡副标题、全部变体名称、原始 No. 编号、“使用者”“按难度”“取得 / 解锁 / 总数”“最高得分”“取得”“本篇”均保留。此项目没有导入参考游戏的个人解锁和成绩：“解锁”显示本机实际关卡内已遇见的变体数量，“总数”始终为完整原典目录数量。

四种组合均保留原典描述：灵梦为“博丽神社的巫女小姐”，速度／范围／攻击力为 3／4／3；魔理沙为“东洋的西洋魔术师”，为 4／1／4。御札与 Bomb 分别为 Homing Amulet／梦想封印、Persuasion Needle／封魔阵、Magic Missile／Stardust Reverie、Illusion Laser／Master Spark。

## 记录与验证

配置升级为 version=8，独立记忆符卡练习的四种组合、七关、符卡组和难度，不覆盖普通 Start 的御札／模式。记录按四组合与原典 1～131 编号分开保存，使用稀疏 `spell_record_*` 行；最高分为非负 64 位数，尝试／取得次数上限 20 亿。练习与本篇（普通开局、整关练习）分别记录尝试和捕获，本篇不覆盖练习最高分；预览和调试靶场不写入。尝试开始即保存，返回或重试不会漏掉已经游玩的尝试；捕获只在无 Miss、无 Bomb 的实际击破时记录一次。旧版整关最高分不会被猜测为符卡成绩，较低分不覆盖旧记录，设置恢复默认也不清空记录。

练习启动必须同时满足战斗已实现与 `Records::Seen(character, number)`。只读取当前角色／御札组合的该编号 `mainAttempts>0`；灵／梦／魔／恋的解锁、取得数和最高分分别保存，不同难度使用不同编号，也不相互解锁。关卡列表的解锁数随当前组合切换。Boss 从非符进入符卡、展示宣告的本帧立即写入该组合的本篇尝试，不必取得符卡，立刻暂停返回也会保留解锁。练习自身的尝试、取得和最高分不能解锁，旧版整关成绩也不能作为遇见证明；已有记录本身按四种组合分开，直接按所属组合判定，无需新增配置字段或复制其他组合的解锁。

核心测试检查 131 个连续编号、七关总数、50 组、难度空槽、使用者、四组合独立遇见解锁、难度隔离、练习不能自解锁、成绩隔离、无效配置与迁移；窗口测试检查新档键鼠拦截、预览不能解锁、普通关卡和整关练习的宣告即解锁、切换组合不能借用解锁、重启持久化，以及同页两级键盘递进/返回不重播进场、鼠标无需点击跨栏、难度空槽、静止指针不抢焦点、全部键鼠别名、箭头点击不穿透、未实现项、Extra、十六组翻页、暂停返回、成功与超时、Replay 灰色及五种窗口比例。可单独运行：

```bash

./build/macos-release/koumakyou_settings_ui_tests output/stage1-review/spell-practice --spell-only
```
