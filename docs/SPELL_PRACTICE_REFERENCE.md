# Spell Practice 新典对照

本次通过本机 `output/th06nc-reference.app` 实际操作核对 Spell Practice，并读取同一安装版本的 `th06IN.dat` 与 `th06TL.dat`。实现使用本项目的页底、边框、衬线字体、选择强调、响应式画布与页面过渡；不依赖原游戏运行或临时解包目录。

## 核心流程

### 玩家入口资源

练习入口在创建战斗演员和录像快照前统一初始化。Practice Start 一面不额外增加火力（原生Standard为0，本项目保留最低Power 8的既有三维适配），二面Power 64，三至六面Power 128；残机及Bomb沿用设置。Spell Practice固定为0额外残机（仅当前一条命）、0 Bomb，No.001～002以Power 32开始，No.003～009以64开始，No.010～131以128开始。重试重新应用该入口配置，连续切关保持已获得的库存与Power；不修改持久设置或上一轮已确认的默认值/重生规则。

依据为同一新典EXE SHA-256 `48630a42a2eb6762d0db2a7e0d151203efbe67220fef7d2f9d0d51857928ac82`：RVA `0x3c860…0x3c886`检查整关练习及关卡号并写64/128；`0x178b…0x17ee`显式构造零起算0/1→32、2～8→64的单符覆盖表；`0x3c932…0x3c947`从覆盖节点读取Power，缺省128，并以word写0同时清零`0x549d40/0x549d41`两个库存字节。`tools/inspect_native_difficulty.py`保护这些代码锚点，合成篡改测试及真实EXE检查覆盖本次结论；不据此宣称原生单符指令准备期已完全还原。

`spell::Card::power`保存符卡入口值，`app/player_start.hpp`由战斗启动与录像兼容校验共用。录像片段记录实际Power及库存，不能再把单符入口固定写成128；不符合新入口资源的录像会被拒绝播放。

首页 Spell Practice → Boss 选择 → 同页符卡与难度选择 → 加载并开始练习。键盘先用上下键或 W/S 选择符卡，Z／Space 确认后操作右栏难度；返回先将焦点交回符卡栏，再返回 Boss 页。两栏始终显示，焦点递进和返回不更换页面、不重新播放整页进场。难度确认后直接加载，不经过普通 Start 的准备横幅，退回首页时仍选中 Spell Practice。

鼠标悬停符卡时立即强调该项并联动右栏内容，无需点击即可直接移入难度栏选择，左键确认难度；也可从右栏直接悬停左栏的另一张符卡。不存在的难度空槽不接管焦点或启动，未解锁及未实现的变体可悬停浏览但不能启动。静止指针不覆盖键盘选择和返回。左右键或 A/D 始终循环切换灵、梦、魔、恋；人物左右箭头点击只切换组合，不能同时确认列表。符卡组超出八行时可继续上下导航、在对应栏目滚轮浏览或点击上一页／下一页。两个栏目独立保存选中强调，当前操作栏目以较强亮度显示。

Boss 和符卡组中的灰色项仍能展开浏览原文，难度中的灰色变体不能启动。原典不存在的难度显示 `------`，也不能跳到其他符卡。当前灵／梦／魔／恋四种御札均接通一至五面四难度及六面N/H/L的 No.001～118 共118个主线变体：一面月符、夜符与暗符，二面冰符／雹符、冻符与雪符，以及三面的道中、风铃、华想梦葛、彩雨、彩光乱舞和台风。月符属于道中遭遇，Easy 暗符的展开技能编号为 3，不能统一套用 Normal 的关底编号。三面关底练习先放行对白等待再推进指定技能。四面新增47张通过单技能命名遭遇进入，展开编号为1，并独立建立前段非符留下的边界和姿态；复用角色准备、攻击及退场，不宣称等同原生 Spell Practice 指令入口。五面新增16张也使用单技能命名工厂，展开编号为1，分别恢复道中或关底的世界边界；四机体工厂检查已通过，32条正式流程与键鼠回归均已通过。六面新增18张使用单技能工厂，展开编号为1，Eternal Meek选择咲夜立绘；四机体宣告、实际发射和退场检查已通过，键鼠、解锁/组合隔离、重启持久化回归已通过，36条正式击破/超时流程也已通过。Extra新增No.119～131共13张单符练习，合计131个可练习变体：119～121使用帕秋莉，122～131使用芙兰朵露，均为展开技能1。UI仅显示EXTRA槽4，战斗内部使用Extra独立关卡的Normal上下文与rank初值18；七关符卡映射不扩充六项整关练习列表。单符跳过整场入场/对白，保留角色技能自身准备与Bomb反应；芙兰光圈显式绑定ExtraEnemies图集。132～134不进入练习目录。新存档须先以当前组合在实际关卡内遇见才可练习；难度卡片分别标注“已解锁／未解锁／尚未实现”。魔理沙使用独立 player01 的主副弹和星形副机，不借用灵梦机体。御札射击实现见 [魔理沙御札对照](MARISA_SHOTS_REFERENCE.md)。

结算保留“返回符卡选择画面／保存Replay／重试”，默认重试；Replay 已接入保存询问及命名，详见 REPLAY.md。Success／Failed 与暂停共用圆角浮窗、居中文字、选中金色下划线和过渡效果；标题下独立保留分数及 Graze／Miss／Bomb 统计区，绘制与鼠标命中使用同一布局。成功捕获显示 Success；普通符卡超时、受击、Bomb或失败不能记为捕获，130号生存符按实际超时且无Miss/Bomb取得。Extra练习结束进入符卡结果，不进入整关Extra的命名选存，不写主线/Extra排行榜或结局观看记录。暂停另有返回符卡选择，结束或返回后保留 Boss、符卡、难度和组合，释放战斗资源并显示光标。

## 完整目录

`src/app/spell_practice.cpp` 保存从 `spellpractice.msgpack` 的 `entries` 与 `localization.msgpack` 的 `zh-CN` 项提取的只读目录。原始条目为 `[编号, 关卡, 脚本编号, 难度, 关内符卡组, 道中标记, 本地化键]`；源码的编号为原始编号加一，难度 0～4 对应 Easy、Normal、Hard、Lunatic、Extra。符卡组按原典归并，不按名称猜测：同组的不同难度可以有不同名称。

浏览目录按实际使用者组织，同一 Boss 的跨关卡符卡合并到同一列表；第二层直接展示符卡名称，名称随当前难度联动，缺少该难度时显示本组首个有效名称。每行附原关卡标签，右栏保留全部实际难度、No. 编号与记录。

六面 Eternal Meek 归入咲夜，Extra 前三张归入帕秋莉。`Bosses()` 的静态组表引用原 `stage/group`，`Selection`、配置、战斗入口和录像继续使用原身份，Boss 序号及列表行号不写入持久化。旧存档无需迁移即可定位到实际使用者；从帕秋莉主线符卡切到 Extra 时仅显示 EXTRA，切回主线时重新校正为有效难度。返回 Boss 列表再确认保留原符卡；更换 Boss 时从其第一组开始。

“取得 / 解锁 / 总数”按实际 Boss 归属与当前组合汇总；总数包含全部难度变体。此项目没有导入参考游戏的个人解锁和成绩：“解锁”显示本机实际关卡内已遇见的变体数量。
四种组合均保留原典描述：灵梦为“博丽神社的巫女小姐”，速度／范围／攻击力为 3／4／3；魔理沙为“东洋的西洋魔术师”，为 4／1／4。御札与 Bomb 分别为 Homing Amulet／梦想封印、Persuasion Needle／封魔阵、Magic Missile／Stardust Reverie、Illusion Laser／Master Spark。

## 记录与验证

配置独立记忆符卡练习的四种组合、原始关卡、符卡组和难度，不覆盖普通 Start 的御札／模式。练习目录保留原典131张；战斗记录按四组合与编号1…134分开保存，使用稀疏 `spell_record_*` 行。`kRecordCount=134`独立于`kSpellCount=131`：132…134只记实际追加战的遇见/取得，不新增练习入口，也不接受练习最高分或尝试数；读取设置同样拒绝这三张的伪造练习字段。原生宣告/取得的134容量与0x180步长有机器码核验，见`NATIVE_DIFFICULTY_EVIDENCE.md`。最高分为非负64位数，尝试／取得次数上限20亿。练习与本篇（普通开局、整关练习）分别记录尝试和捕获，本篇不覆盖练习最高分；预览和调试靶场不写入。尝试开始即保存，返回或重试不会漏掉已经游玩的尝试；捕获只在无Miss、无Bomb且满足本技能成功条件时记录一次，生存符可以超时成功。旧版整关最高分不会被猜测为符卡成绩，较低分不覆盖旧记录，设置恢复默认也不清空记录。

练习启动必须同时满足战斗已实现与 `Records::Seen(character, number)`。只读取当前角色／御札组合的该编号 `mainAttempts>0`；灵／梦／魔／恋的解锁、取得数和最高分分别保存，不同难度使用不同编号，也不相互解锁。Boss 列表的解锁数随当前组合切换。Boss 从非符进入符卡、展示宣告的本帧立即写入该组合的本篇尝试，不必取得符卡，立刻暂停返回也会保留解锁。练习自身的尝试、取得和最高分不能解锁，旧版整关成绩也不能作为遇见证明；已有记录本身按四种组合分开，直接按所属组合判定，无需新增配置字段或复制其他组合的解锁。

核心测试逐张以四种御札核对131个已接通变体的实际遭遇、展开技能及角色声明。一至三面的74条击破/超时完整流程已通过；2026-10-29四面新增47张的94条正式流程也全部通过，检查默认120 Hz、暂停、记录次数各增一次、整关成绩隔离及返回选卡时的资源释放。可用 `--difficulty-spells` 重跑全部主线变体，`--extra-spells` 单独核对Extra十三卡的四御札与自然超时/击破，或用 `--stage4-spells`、`--stage5-spells` 单独验证四/五面。五面新增16张的32条正式流程均已通过。

符卡和整关练习窗口输入回归均通过。一至三面代表性编号为1、6、13、14、20、21、24、25、29、31、34、37；四面新增38、44、48、55、62、65、69、73、77、80、84，先通过实际整关机体分支宣告以解锁，再以键鼠启动、核对机体/编号、暂停和返回，不直接写入遇见记录。五面新增85、88、89、91、92、93、95、96、97、99、100，分别沿真实道中或关底遭遇声明解锁，新增窗口回归已通过。

Boss 归属回归另检查七位使用者的50组、131变体恰好覆盖一次、咲夜六面归属、帕秋莉主线/Extra切换、芙兰翻页及旧选择恢复；可用 `--spell-boss-only` 单独运行窗口回归。
