# 灵梦追踪弹的新典数据对照

本分支从本机 Steam 安装的 `th06nc.exe` 直接解析灵之御札（Reimu A）的火力表，恢复 cyan 追踪弹的 Power 分档、发射周期、相位、左右成对模块和初始横向张角。金色直射弹仍使用项目现有规则。

## 输入与解析

- 输入 SHA-256：`48630a42a2eb6762d0db2a7e0d151203efbe67220fef7d2f9d0d51857928ac82`。
- 灵梦 A 火力表：RVA `0x427a00`，九个 16 字节记录，包含弹数、下一档 Power 上界及 64 位弹表指针。
- 单发记录为 36 字节：`<hh6fHBBhh`；前两个有符号 16 位整数分别为周期帧数、周期内相位；追踪弹 `bulletType=1`、`anmFileIdx=1121`，左右模块为 `spawnPositionIdx=1/2`。
- 本版本的上界为 `8,16,32,48,64,80,96,128,999`，取首个严格大于当前 Power 的档位。旧版公开还原中的倒数第二个上界为 127，不能直接代用。

调用及计时语义已按同一输入的反汇编核对，以下地址均为 RVA：

- `0x6bf50` 的 Reimu A 回调引用 `0x427a00`；字符配置中普通/低速两个回调均指向它（配置 RVA `0x429000`，回调字段 `+0x10/+0x18`）。
- `0x6bc90` 根据 Power 选择档位；`0x6bd37…0x6bd48` 检查 `frame % period == phase`。
- `0x6ae14…0x6ae36` 在射击按下且计时空闲时启动第 0 帧；松键不取消已经启动的窗口。
- `0x6b38a…0x6b3b4` 推进计时，达到 30 帧后置为空闲；持续射击在下一个逻辑帧重新从 0 开始。

[th06 引擎还原的字段定义](https://github.com/GensokyoClub/th06/blob/master/src/Player.hpp)和[射击流程](https://github.com/GensokyoClub/th06/blob/master/src/Player.cpp)仅用于辅助辨认结构，本表数值与 128 边界来自上述新典输入。

重新导入只需要 Python 标准库，不启动或修改原游戏：

```bash
python3 tools/import_reimu_homing.py /本机安装目录/th06nc.exe
```

脚本解析 PE64 节表并定位唯一满足 Reimu A 结构的火力表，不依赖固定文件偏移；结构、模块、相位或候选数量不符合预期时报错。输出 `src/gameplay/actors/reimu_homing.hpp`，保留输入哈希与表 RVA。原游戏、反汇编全文及解包缓存不入库。

## 60 Hz 发射表

每个时间点的“一对”均为左、右模块各一颗，角度为相对正前方的单侧横向角。连续射击时以下 0…29 帧窗口重复，帧数除以 60 即为秒数。本项目开局 Power 和下限均为 8；表中 0～7 档保留新典原始数据，游戏中不会进入该档。

| Power | 窗口内发射帧 → 单侧张角 | 每窗口颗数 | 连续射击每秒颗数 |
|---|---|---:|---:|
| 0～7 | 不发射追踪弹 | 0 | 0 |
| 8～15 | 0 → 30° | 2 | 4 |
| 16～31 | 0 → 30° | 2 | 4 |
| 32～47 | 0 → 30° | 2 | 4 |
| 48～63 | 0、15 → 30° | 4 | 8 |
| 64～79 | 0、15 → 30°；0 → 60° | 6 | 12 |
| 80～95 | 0 → 20°；10 → 40°；20 → 60° | 6 | 12 |
| 96～127 | 0、15 → 20°；5、20 → 40°；10、25 → 60° | 12 | 24 |
| 128 | 0、16 → 20°；4、20 → 40°；8、24 → 60°；12、28 → 80° | 16 | 32 |

Power 64～79 在第 0 帧同时发两对，第 15 帧发一对；80～95 总弹数相同，但改为三次错开发射。满火力原始通道周期为 16 帧、相位为 0/4/8/12，仍受 30 帧窗口约束，所以第 28 帧到下一窗口第 0 帧只隔两帧，不能将计时替换为无限延伸的 16 帧周期。

## 三维接入与验证

追踪弹与金色弹使用统一逻辑窗口，各自按原始通道周期调度，Focus 不加快追踪发射；切换 Power 时在原周期相位上换表，不补发已错过的通道。一次点射完成当前 30 帧窗口，禁火对话和复活取消当前窗口。小数逻辑帧跨更新保留，低帧率逐帧补发，避免显示帧率改变弹量；补发使用当前帧姿态和瞄准快照。

Power 8 起显示原生左右旋转太极圈，副弹出生点与 `Player::OptionPositions()` 返回的圈中心完全共用；常态单侧距离 0.78 世界单位，Focus 在 8/60 秒内平滑缩至 0.26，松开后展开。两圈在视点前方 1.2、屏幕下方 0.35 世界单位，近距离位置与圈尺寸等比缩放。保留准星汇聚：原始角度映射为目标平面上的对称散射落点，近距离等比缩短模块偏移。原始速度 10 像素/帧换算为约 16.67 世界单位/秒，伤害直接使用各档原值；转向率 5.5 弧度/秒、Alpha 51 和最近目标追踪保留三维适配。当前权威运行时数据为 `native_combat`；旧专用导入器及头文件仅保留历史核对用途，不再参与游戏。完整导入步骤见 [原始战斗数据接入](NATIVE_COMBAT_DATA.md)。

玩家回归测试逐帧核对 Power 8 起八档及上下边界、连续两个窗口、每对左右模块、各相位张角、30/60/144 FPS、Focus 切换、点射尾窗、禁火取消、Power 升级和复活重置，并检查受击与调试扣减不低于 8。隐藏窗口射击测试检查真实 ANM 追踪弹的可见像素，首次发射仅计当帧到期的通道。
