# 课程汇报素材清单

本文对应[逐页 PPT 脚本](COURSE_PRESENTATION_SCRIPT.md)，列出网站、文档、截图、图表、录屏和运行包。状态以当前仓库核对结果为依据；“待补／待核实”不等于认定外部平台未完成。

## 优先级和状态

- P0：主 PPT 与现场演示需要的材料。
- P1：课程提交、Wiki 或答辩备查需要的完整材料。
- P2：可选增强材料。
- 已有：存在可利用的本地材料，仍需核对最终版本。
- 待制作：需要从项目提取、绘图、录制或编排。
- 待补／待核实：本地未找到完整交付证据，需要确认真实状态。

建议文件名是整理约定，不表示对应文件已生成。网站的 URL、二维码、截图和本地程序是不同交付物，需要分别准备。

### 录制前准备

1. 固定演示版本、角色、模式、场景和存档，确认练习内容已按正常规则解锁。
2. 熟悉镜头与移动路线，避免快速甩动导致观察困难；使用视觉层次清楚的攻击。
3. 关闭无关通知，使用整洁桌面和稳定窗口尺寸，避免拍入私人文件或账号信息。
4. 检查 BGM、音效和讲解音量；现场讲解时使用较低游戏音量。
5. 单独录好结果或录像片段；剪辑跳转处明确标注“片段切换”。
6. 导出 MP4 / H.264 后，在实际播放设备检查画面、音频、字幕和拖动播放；保留原始文件。
7. 无论是否选择现场操作，均准备本地可播放的主片和压缩版。

## 八、最小准备顺序

1. **固定事实**：D01 最终范围、D03 真实分工、D08 最终测试、D10 发布说明；不能确认的内容保留待填。
2. **补齐入口**：W01、W03～W05，先保证项目与 Wiki 页面能访问、软件能下载运行，再制作二维码和发布页截图。
3. **采集画面**：S01、S03～S07、S09、S10、S13，并录制 V03，随后剪出 V01 和 V02。
4. **制作图表**：G02～G06，图形与对应数据一起保存。
5. **装配幻灯片**：按逐页脚本放置画面、上屏短句和演讲者备注。
6. **现场验证**：检查链接、扫码、离线播放、音量、字体与运行包，完成两轮计时排练。
