# 一面子程序到带参行为的映射

当前 Normal 内容在既有行为基准上完成三维延拓，涵盖五种道中敌人、道中露米娅、关底四阶段及准备、击破和退场。出生时点、HP、镜像作用域、随机种子、掉落与动画时点保留；编队整体高度、等路程三维位移和弹幕面积分布属于项目适配；原队列的 X/Z 轨迹及 Boss 移动、攻击空档保持。正文中的原参数案例以 Normal 为基线；目前四难度整关练习已接入，包含 Hard/Lunatic 道中 Moonlight Ray 和 Easy 跳过 Night Bird。四难度及入口验证范围见 [集成记录](DIFFICULTY_INTEGRATION.md)；本项目练习复用角色行为，不宣称复刻新典的原生练习执行路径。

从原典数据提取、语义分析到当前实现的完整方法与原则见 [Stage 移植方法](STAGE_PORTING_METHOD.md)；本文保留具体配方、子程序映射和时序不变量。

## 运行结构

`timeline.cpp` 直接定义固定的 `std::array<StageEvent,226>`，显式列出 222 次杂鱼出生和 4 个 Boss/对话事件；不通过 lambda、循环或原始数值目录构建时间轴。每次出生的帧号、坐标、HP、分数、掉落、镜像、随机横坐标标记、种子和外观均直接写在表中，五种命名行为配方以 `behaviors.hpp` 中的 `inline constexpr` 常量共享复用，生产代码直接按名称引用。`Spawn` 只封装已给定的世界坐标参数，不转换坐标。每个参数对象按值保存 `pattern.movement` 与 `pattern.skill`；`SpawnActors` 直接携带 `behavior::Spawn`，由 `ActorPool::Spawn` 启动独立 `behavior::Actor`；没有小怪工厂或用于运行时选择路径的 `sub` 字段。

- `gameplay/actors/movement.*`：极坐标运动及等路程三维延拓、定时转弯、速度/加速度变更、三维插值、X/Z 与可选高度边界。
- `gameplay/actors/skill.*`：固定/瞄准扇形与环形、等面积球面/球冠方向采样、速度层、显现、发射加速、延迟转向/重新瞄准和三维固定瞄准光束。
- `gameplay/actors/behavior.*`：`Pattern`/`Spawn` 配置、`ActorPool`、120 Hz 更新与 60 Hz 内容时钟、局部子行为调用；同一 `Actor` 保存战斗、动画、入场/回收状态，不认识 ECL 操作码。
- `stages/stage1/behaviors.*`：道中配方及露米娅命名阶段，复用移动和技能组件。
- `tests/reference_script.*`、`tests/reference_program.hpp` 与 `tests/reference_coordinates.hpp`：保留重构前解释器和指令，只编译进测试；生产引擎和游戏不再链接它。

## 世界坐标与单位

生产代码已经移除 `movement::Space` 和 `stages/stage1/coordinates.hpp`。时间轴直接保存世界出生点，`Actor::Activate` 直接初始化 `motion.position`，碰撞与渲染读取同一世界位置；`Position()` 不再投影。移动速度为世界单位/秒，默认每个更新步按 `1/120` 秒积分，行为时刻仍使用 60 Hz 内容帧。正式 Game 的玩家、弹池与碰撞同样按 120 Hz 战斗步执行。`behavior::UpdateRate::Hz60` 保留给原作差分测试，生产演员池和 `RumiaBoss` 均默认 `Hz120`；频率固定在实例上，重置和槽位复用不会改变。

`Pattern::muzzleOffset`、`skills.offset` 为世界 XYZ 偏移，`Shot` / `ProjectileMotion` 的速度和加速度直接交给弹池，不再缩放；`Laser` 的长度/全宽为世界单位，等待与显现时间仍按帧配置。rank 弹速修正也使用世界单位/秒。默认回收边界为世界 X≈±9.285714、Z≈±10.714286，随机出生横坐标范围为 X≈±8.571429；Boss 的平面编排继续使用原巡航边界 X≈±7.142857、Z≈3.571428…7.857143。`Bounds` 仍只约束 X/Z；普通演员另设 `retirementHeights=[-10.5,10.5]`。Boss 高度目标为 [-1.25,1.25]，高度移动计入原路程预算，不用大范围体积路点驱动。

## 以空间均匀为原则的三维延拓

本节是项目适配，不是新典 ECL 原始参数。固定平面的旋转复制、`zCopies` 和 `planeRoll` 已移除；弹幕按球面面积或锥内立体角采样；演员演出优先保持原队形、原位移量与原节奏，空间分布仅在这些约束内调整。

### 弹幕方向

- 环形扩展为近似均匀球壳：`cos(θ)=1-2(i+0.5)/N`，方位按黄金角递进。各方向代表相同球面面积，不会在极区或轴线上叠加平面副本。
- 扇形扩展为球冠：`cos(θ)=1-(1-cos(α))(i+0.5)/N`，α 为半张角。方向数量与角范围分别配置，局部正交基底仅负责朝向真实玩家；固定图案不依赖玩家位置。
- `Shot::spatialCount` 表示每速度层的方向总预算，0 时沿用原 count。一面多向攻击以原基础弹数的三倍作为预算，rank 弹数修正在总预算上应用一次，不再按副本重复修正。普通七向妖精使用 21 个方向、α=1.1 弧度；Boss 普通扇形按源角距取 α 并限制在 0.25…1.1 弧度。环形覆盖整球。道中首轮为 48×3=144 弹；暗符 rank=16 时为每壳 48+1=49，双壳共 98 弹。
- 普通单弹串保持真实玩家中心瞄准；扫描流的 `sampleIndex` 从 60 Hz 阶段内容帧确定，用 Halton(2,3) 均衡覆盖球冠的面积分位与方位，α=0.9 弧度。四色和双向扫描保留颜色顺序、速度递增与逐发时点，不通过旋转几张平面填充空间。
- 速度和加速度表示真实模长，显现、发射加速、延迟、rank、颜色和技能上下文继续独立保留。零初速弹保存 `launchDirection`，启动加速也沿各自方向展开，避免全部退化为固定轴。
- 暗符每个方向使用独立单位切向轴完成延迟 ±90° 转向。重新瞄准以转向时真实玩家为准，不使用虚拟目标；六光束仍逐次三维锁定，数量和危险时窗不变。

速度层保留原始速率结构，所以“均匀”指每层的角面积分布，不意味着不同半径球壳具有相同单位体积密度。源相位和有意设置的层间错相仍保留。

### 出生与普通演员走位

222 条显式出生恢复原来的 X/Z、镜像、randomX、种子、帧号、HP、掉落与外观。同一个原有编队整体平移到一个固定 Y 高度（-1.5、1.5、-0.75、0.75、0），高度直接写在表中；不逐只重排 X/Y，也不按独立随机目标改变队列走向。

五个道中配方恢复原极坐标路线、转弯、停车、加速与退出时点，整段保持本波的 Y 高度。队列的前后间距、左右镜像和弯曲形状由原参数直接保留，随机横坐标仍在出生时按原固定种子求值一次。原逐只空间巡航的 `Coverage` 接口已移除。

验证同时运行实际空间出生配置和独立原行为：每只逐帧比较 X/Z、活动/回收状态，并检查 Y 始终等于其编队高度。攻击继续使用新的球面/球冠采样，移动与发弹配置互相独立。

### Boss 等路程位移与节奏

Boss 继续使用原入场、巡航、符卡准备和退场目标与时长，不再前往全活动体积采样点。`movement::LiftedPath` 保存一份世界 X/Z 编排状态，仍由同一个命名阶段协程写入速度、随机转向、边界、插值与停顿。它不依赖关卡编号或 ECL；真实三维位置始终保存在 Actor::motion，碰撞与渲染直接读取该位置。

每段移动开始时，以独立序号选择 [-1.25,1.25] 内的保守高度目标，将原位移方向的一小部分分配给 Y，竖直分量最多为该段路程的 1/4。每个逻辑步以原平面编排**实际发生的合位移长度**作为三维距离预算，包含边界夹取和插值终点补偿，不能把两段补偿长度相加而额外加速。因此既保持每步及平均位移量，也保留原插值缓动、停止时刻与跨阶段剩余时间；原地不动时不为追逐高度新增位移。

随机巡航继续进行原来的一次方向读取和原 X/Z 边界反射，减速移动按原 speed×duration/120 的名义距离编排，实际交付仍遵循旧边界语义。阶段切换保留移动状态与空间序号。首个非符原有的 100 帧等待、第二非符 200 帧准备不追加移动；夜符/暗符的 120 帧准备、六光束、逐发扫描和退场等待沿用原内容帧。

新增同频率对照逐步比较 Boss 平面编排、实际三维位移长度、发射弹种/颜色与光束时点、音效、掉落、HP、受伤开关和回调；同时检查等待期间完全静止。空间攻击图案可以改变，攻击和移动节拍不能改变。

### 时钟与独立基准

正式 Game 继续以同一 120 Hz 战斗步推进关卡、对话、玩家、演员、弹池、Bomb 和碰撞；60 Hz 内容时点、等待、超时和自机火力窗口不加速。暂停不积累墙钟时间，重开清空移动编排、余量、输入和挂起协程。

原作差分继续显式使用 Hz60。普通敌人的中性配置仅去除编队高度并关闭 spatialShots；Boss 使用 `ConfigureBehavior(actor,false)`。旧解释器与原始期望不改、不扩大误差。新增球面密度与受约束走位使用独立几何和等路程测试，不能拿新配方重新生成“原作答案”。

## 时序不变量

1. 每个固定更新步先应用上一更新步速度，再执行当前移动/技能编排，最后计算下一帧速度。不能交换该顺序。
2. 子行为有独立局部时钟，调用期间父行为时钟冻结；子行为返回后父行为在同一更新步继续。阶段总计时与动画时钟独立推进。
3. `Update` 跨显示帧补算固定 120 Hz，每步前进 0.5 个 60 Hz 内容帧；暂停不推进；阶段回调发生后保留未消费逻辑时间。重开和销毁会释放全部挂起行为。
4. 运动状态、插值目标、边界及技能参数直接采用世界坐标和每秒速率；世界 +Y 为高度，极坐标正角度从 +X 朝 -Z。镜像只作用于 X；生产启用三维单位方向及等面积采样，旧高度坡度只供中性适配差分。原作像素到世界的映射只保存在测试基准，生产代码不执行坐标换算。
5. 角色的随机数状态独立；读取次数和顺序必须保持。通用随机横坐标仍只在出生时求值一次；一面保持原显式 X/Z 与 `randomX` 标记。
6. 道中出生 HP 在事件表中显式给出，并与统一原始目录回归核对；Boss 内部技能定义仍从统一目录绑定生命/预留偏移/超时，命名阶段回调与原始回调关系由差分测试核对。
7. 清弹只重置原有 rank 修正，不清除运动或后续技能上下文；已经生成的弹拥有自己的运动参数副本。
8. 插值先计算世界位移再与起点相加；世界单位积分改变了旧像素运算的舍入位置，60 Hz 对照模式单独约束累计位置误差，阶段与发射时序、随机分支仍须精确一致。

## StageEvent 衔接

道中出生仍使用原始 `atFrame`，道中 Boss 在 1882 帧开始，战斗期间不暂停关卡时间轴，Boss 存在时到期的杂鱼请求由游戏跳过。5092 帧进入战前对话；关底 Boss 使用 `afterEndOf` 等待该对话结束；战后独白再依赖关底 Boss 结束。事件 ID 和异步完成规则保持原样。随机种子为保持旧行为而固定为原值，之后插入其他事件不会隐式改变既有敌人的随机状态。原始目录更新后需要人工同步事件表；差分检查会报告出生参数或时序不一致。

扩展敌人时可直接构造 `behavior::Spawn`，修改 `pattern.movement`、`pattern.skill` 和 `visual`，再放进 `SpawnActors`；不必增加子程序编号或修改解释器。配置校验会拒绝非有限值、错误关键帧顺序、超出寿命的技能及非法弹数/外观。

## 验证

`tests/behavior_tests.cpp` 显式关闭新增空间适配，并将实现设为 `UpdateRate::Hz60`，与固定 60 Hz 的重构前解释器对照，比较第一次不一致的帧，期望值不从新配方生成：

- 覆盖当前 Normal 可达的 28 个原子程序，包括所有非符随机分支和符卡辅助程序；覆盖率由旧解释器独立记录。
- 使用 30/60/144 FPS、rank 10/16/32、三个随机种子、镜像和动态三维瞄准目标，并插入零时间更新。
- 比较逐帧位置、HP、免伤、动画编号/重启次数/年龄、音效、掉落、回调、阶段时间，以及实际弹池槽序和所有敌弹运动/光束参数。
- 对 222 条真实出生记录逐条检查时间轴参数、行为实例、随机出生坐标、运动、技能及自然退场。
- 连续经过伤害阈值或超时驱动的关底阶段，验证跨阶段保留状态、清弹、准备期及退场。
- 生产默认 120 Hz 的独立回归：半帧移动、技能时刻、子时钟冻结、阶段超时、剩余时间、池复用，以及 30/60/120/144/240 FPS 下的同频率轨迹一致性。
- 独立组合自定义路径和技能，验证非法配置拒绝，以及重开/销毁时父子挂起行为的资源释放。
