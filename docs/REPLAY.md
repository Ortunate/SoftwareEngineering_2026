# Replay 使用说明

正常关卡流程结束后询问保存 Replay；练习结果页可以选择“保存 Replay”，未保存便重试或返回时询问一次。选择是后输入名称，Enter 保存，Esc 返回询问。命名支持键盘输入，Tab/Insert 提供字符选择。Windows 命名时临时启用输入法；其他平台仍可使用屏幕字符选择。最多 32 个 Unicode 字符，名称不决定文件路径；未收录字形由字体回退显示。中途退出、重试、调试与预览不保存，未来续关后取消保存资格。

录像文件位于启动目录的 `replays/`。主菜单 Replay 选择播放，播放本身不更改玩家设置、最高分和符卡记录。

| 快捷键 | 功能 |
| --- | --- |
| Space | 暂停/继续；暂停期间仍可观察 |
| 左/右 | 后退/前进 5 秒 |
| Shift + 左/右 | 后退/前进 30 秒 |
| Home / End | 开头/结尾 |
| [ / ] / 1 | 减速/加速/恢复 1 倍，支持 0.25/0.5/1/2/4 倍 |
| V / R | 第一人称、第三人称、自由视角循环 / 重置相机 |
| 鼠标 / 滚轮 | 观察方向 / 第三人称距离 |
| WASD / Q E / Shift | 自由视角平移 / 升降 / 加速 |
| Esc | 返回录像列表 |

底部播放栏展示当前状态、进度、时间、倍速、视角和操作提示。播放到末尾停留，可继续倒带。倒带从当前已实现的单关入口重算，显示定位中；每帧限制工作量，连续请求以最新目标为准。暂停、非 1 倍和定位时静音，恢复正常播放时对齐 BGM；跳过的音效不会补播。观察镜头不改变玩家输入和判定。第三人称和自由视角显示现有灵梦/魔理沙角色动画贴图。

可用 `koumakyou --replay <文件>` 直接播放；`--capture-replay <文件> <PNG路径> <秒数> <视角0/1/2>` 用于隐藏窗口导出画面。

协议及未来四难度、六面、Extra 的接入约定见 [v2 协议](REPLAY_PROTOCOL.md)。当前只实现 Normal 一面；旧版或尚未实现内容仍保留文件，不允许错误回退播放。

本轮按用户要求未新增或修改单元测试。既有 Replay 测试预期自动保存、v1 和结束自动返回列表，与新版不兼容，不能将旧二进制的结果作为新版验收证据。核心与 UI 的既有检查可独立运行。此前默认 framebuffer 像素断言失败已在未修改的 95d2689 复现。
