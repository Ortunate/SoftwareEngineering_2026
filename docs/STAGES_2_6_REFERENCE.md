## 独立计数与证明边界

`tools/inspect_stage_scripts.py` 直接只读解析二进制结构，保留指令偏移、完整难度/参数掩码、局部帧、原始参数字节、出生配置与调用关系。格式对照 [thtk 的 TH06 格式表](https://github.com/thpatch/thtk/blob/master/thecl/thecl06.c)。没有复用或放宽一面专用的 38 子程序导入校验，也没有把原始指令链接进生产引擎。

五关共有 **1657 条时间轴出生记录**，此数包括上表的 Boss 出生记录，不代表 1657 只普通敌人，也不包含子程序内使魔出生的动态次数。出生记录本身没有难度掩码；其目标行为内部再按 Normal 指令掩码筛选。

“保守可达”从全部时间轴出生入口开始，对普通调用、条件调用、子演员出生、死亡/中断/生命/超时回调求闭包；没有执行条件分支，也没有筛除指定御札不进入的分支。因此这些计数不能称为实际游玩覆盖率，更不能作为完成移植的验收结论。报告中的指令帧是局部时钟，时间轴帧是源脚本时间；遇到源脚本等待时，不能直接把所有数值当成项目开局绝对帧。

特别是三、五、六面出现了道中对话入口，六面的对话与出生等待也不同于一面。新事件表须先恢复等待及结束依赖，再决定哪些事件可用 `atFrame`；不能复制一面的“道中时钟一直前进”策略。

## 复现静态审阅

将对应版本文件只读解包到临时目录后运行：

```bash
python3 -B tools/inspect_stage_scripts.py \
  /tmp/stages-porting-source/ecldata2.ecl \
  /tmp/stages-porting-source/ecldata3.ecl \
  /tmp/stages-porting-source/ecldata4.ecl \
  /tmp/stages-porting-source/ecldata5.ecl \
  /tmp/stages-porting-source/ecldata6.ecl \
  --difficulty N --output /tmp/stages-porting-audit
python3 -B tests/test_stage_script_inspection.py
```

输出的逐文件 JSON 用于检查原始结构，`coverage.json` 保存上述保守闭包与扩展指令清单。工具拒绝越界区段、截断指令、非法引用、非指令边界跳转和非有限出生位置；未知指令保留原始参数，不编造执行语义。默认生命出生明确保留 `null`。

合成测试独立构造文件，覆盖难度筛选、调用/使魔/回调闭包、循环引用、关闭的回调、当前指令相对跳转、未知扩展保留、默认生命缺省和损坏文件拒绝。测试不依赖本机安装。
