# 普通弹体性能记录

以下为第二轮完整 111 次实验的历史基准：Intel Core i9-14900HX / RTX 4090 Laptop GPU，1920×1080、OpenGL 3.3、无 MSAA/垂直同步/限帧，预热 3 秒、采样 10 秒、三次重复。

其后泡弹加厚光圈、收紧暗中心和尖丝内端，执行过短时诊断；最终碰撞改为光圈内缘以内的整体体积后，资产及碰撞回归通过，但未重跑完整性能实验。下表泡弹与相关混合场景不能当作最终版本的完整性能结论。极近覆盖与大量窄相候选超预算仍是已知边界。
