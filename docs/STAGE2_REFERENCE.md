# 二面 Normal 接入记录

目标分支为 `heny/stages`。输入来自新典 `th06ST.dat` 的 `ecldata2.ecl`、`msg2.msg`、`stg2enm.anm`、`face05a`，音乐为原包 `th06_04` / `th06_05`。ECL / MSG 哈希见 [逐关输入记录](STAGES_2_6_REFERENCE.md)；完整解包和机器码审阅文件不进入运行时。

## 已接入范围

`src/stages/stage2` 提供独立素材清单、显式事件表、12 种命名普通配方、大妖精道中、琪露诺五阶段、灵梦/魔理沙前后对话与湖面背景。内容目录和 `native_combat` 导出规则同时登记 `Playable`。原生 Stage / Spell Practice 入口、其他难度和全关连续流程仍需单独实现，不能由数值目录推定已经开放。

468 条事件包含 464 次普通出生及两场 Boss、两段对话。道中 Boss 源帧为 2498，战前对话为 5893；关底等待战前对话实际结束再延迟 1 帧，战后对话等待关底实际结束再延迟 2 帧。道中时钟继续；Boss 活动期间到期普通出生跳过，入场保留既有对象，对话清场。普通出生的生命、分数、掉落、镜像与随机 X 标记逐条对照原始目录。

琪露诺顺序为非符、冰符「Icicle Fall」、非符、冻符「Perfect Freeze」、雪符「Diamond Blizzard」。两组原始 HP 为 10000 / 13000，阈值分别为 1500 / 3200 / 1400；最后两张连续符卡共享第二组预留血量。正 HP 阈值击破也能捕获 Perfect Freeze，超时不会误捕获。阶段保护在伤害交接当帧生效，完整退场后才报告遭遇完成。大妖精击破显式掉落 Bomb，超时不掉落。

## 语义核对

格式表对照 thtk，经典版还原工程仅作为定位线索。以下副作用另核对同一新典 EXE（SHA-256 `48630a42a2eb6762d0db2a7e0d151203efbe67220fef7d2f9d0d51857928ac82`）：

- ECL `77` 的 RVA `0x26784`：周期先取 `interval / 5` 整数端点，rank 项整数截断，再相加；初始计数使用一次无符号随机整数取模，配置时保留 rank 快照。不能改为浮点比例取整。
- 扩展表 RVA `0x34ddf0` 的第 0 项指向 `0x34290`：遍历有效普通敌弹，改色为 15；参数 0 清速度，参数 1 设置随机方向、0.01 源加速度和 220 帧持续时间。生产中加速度为约 1.60714281 世界单位/秒²，不修改玩家弹或光束。
- 第 1 项指向 `0x34480`：先读取随机 X，再随机 Y；宽为传入的 128，纵向跨度乘 0.75。生产保存对应世界跨度，不恢复像素转换。
- `123` 只改变当前子行为局部时钟；阶段总时钟和父行为等待不随之加速。

随机序列使用项目固定出生种子和实例 xorshift；保留读取次数、顺序和整数/浮点运算类型，不宣称等同原生全局 RNG。共享随机发射模式每弹先角度后速度，溢出请求仍消费应有随机读取。

## 三维边界与验证

普通演员保留源 X/Z 队列，同一连续波共享高度。Boss 沿原 X/Z 移动预算保守分配高度，攻击使用直接球面/球冠采样；空间序号独立于攻击随机流。湖面背景为项目三维适配，未复刻原生背景模型。世界边界回收采用独立世界积分作离散对照；源像素积分只用于轨迹差分，边界附近的浮点累计不能混作同一个离散基准，也未为回收添加容差。

`tests/stage2_tests.cpp` 在 60 Hz 下逐只核对普通运动、动画选择、出生和周期发射，并以独立源参数记录检查大妖精首轮/瞬移、非符首轮、Icicle Fall、冻结/解冻和 Diamond Blizzard 首发。轨迹误差上限为 `5e-4` 世界单位；默认 120 Hz 另在 30/60/120/144/240 显示 FPS 核对位置、实际发射、动画及后续随机值。该测试是首次移植的独立参数/见证记录，未将一面旧解释器称作二面完整执行基准。

无窗口 CTest 覆盖出生、配方、生命/超时、三段 HUD、道具及对话时长。`koumakyou_lifecycle_tests --stage2-only` 覆盖两角色无攻击超时通关、五阶段、暂停、零池溢出、实际碰撞击破、Bomb 拾取、符卡记录及切关卸载；截图审阅覆盖琪露诺正确的 `face05a` 立绘与横竖屏名牌。原 `face06` 属于红美铃，不能用于琪露诺。

```bash
cmake --build build-debug --target koumakyou koumakyou_tests koumakyou_lifecycle_tests -j 6
ctest --test-dir build-debug --output-on-failure
./build-debug/koumakyou_lifecycle_tests /tmp/stage2-lifecycle --stage2-only
```
