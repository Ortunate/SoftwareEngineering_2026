## 结构、材质与接口

小刀圆柱柄半径 0.085，Y 范围 −0.46 至 −0.155，孔中心 Y=−0.305；正面椭圆孔半轴 0.035 / 0.095，沿 Z 贯通。布尔开孔后清理重合点和退化边，实体碰撞从最终刀刃、护手、柄体导出，孔内不填充。硬上限 256 面，实际 122 面。

泡弹外半径 0.5、内部球半径 0.22；该比例是本项目三维解释，不声称为原作精确判定半径。内球 120 面、外壳 288 面、48 根闭合四棱尖丝共 288 面；总计 696，硬上限 768。尖丝按 Fibonacci 球面分布，长短交错，处于两球之间，无动画、无碰撞。第五种白色按原图降低尖丝对比度。尖丝端向观察淡出，避免前后端面遮住暗中心；几何在灰模/线框模式仍完整显示。

三种 orb 分别设置径向亮度和边缘过渡，不加原图没有的纹章。继续使用纯色与程序化表面着色，无原精灵拉伸贴图。模型放大到数百像素仍可见低面数轮廓；验收需同时看 8/16/32/64 像素预览和灰模，不能以光效掩盖形体问题。

`CollectionInstance` 保持兼容。角色编码仍为 `COLOR_0.g = role / 2`：0 实体/内球，1 外球壳，2 火焰或尖丝；只有 Type 7 的角色 2 发生动画。碰撞验证读取资产部件的 `collision` 标记所对应角色，不再把所有球壳当碰撞体。

`CollectionRenderer::Draw` 的模式增加 5（仅球壳）、6（仅尖丝/外焰）；原模式编号保留。泡内球以乘法衰减背景，壳与尖丝加色，透明层保留深度测试、不写深度。批次按固定角色顺序绘制，不作逐弹排序；这是风格化表现，不是物理玻璃。高覆盖泛白及跨类型固定混合顺序仍需人工评估。

全部类型共享原实例缓冲，无逐弹 GPU 对象。泡弹开光效四次绘制，光效仅重复外球壳，不重复全部内部结构；三种 orb 三次，小刀两次。正式游戏的命中、擦弹、清弹和连续碰撞尚未接入。

## 独立验收操作

双击根目录 `Review-Projectiles.cmd`，不启动游戏。

- **V**：三种 orb 同色等尺寸、原图比例、退出对照；参考图保持宽高比。
- **6 / 8 / 9**：分别查看泡内球、外球壳、尖丝；**7** 查看全部装饰。
- **4 / 5**：真实碰撞单显、叠加。泡弹危险范围只对应内部球。
- **J**：切到泡弹并循环球间、外壳之外、内球内探针。默认半径下依次 CLEAR、CLEAR、CONTACT。
- 小刀用 **H** 将探针置于孔心，预期 CLEAR；沿 Z 移动检查贯通孔，沿 X 移动进入孔壁应 CONTACT。
- **Tab** 选择弹体，**T** 全色，**B** 背景，**G** 光效；鼠标旋转、滚轮缩放。仍可暂停火球并逐帧查看。

自动截图 `Review-Projectiles.cmd -Action capture-collection` 共 209 张，另含 `orbs-equal.png`、`orbs-relative.png`、`bubble-inner.png`、`bubble-shell.png`、`bubble-filaments.png`、两种泡外探针和 `knife-cylinder-side.png`。输出在 `output/projectile-review/collection/`，不提交截图缓存。
