# Stage 1 录像对照

参考文件：用户提供的 `BetterCapture_2026-09-25-20.19.06.mov`。视频长约 187.06 秒，画面为 1920×1108。以下时间为视频时间码的目视区间，不是逐帧测量值；前几秒包含角色选择画面。`StageDirector` 的时间从按下开始游戏算起，因此和视频时间码存在数秒偏移。

| 视频时间 | 可见内容 | 当前实现 |
|---|---|---|
| 约 3–30 秒 | 蓝色妖精分批入场，随后穿插紫色妖精及少量红色瞄准弹 | 蓝、紫妖精编队 |
| 约 31–54 秒 | 道中露米娅出现，单血条，发射散射弹；退场后道中继续 | 道中普通攻击，击破或超时退场 |
| 约 55–73 秒 | 紫色妖精编队与红色弹 | 紫色妖精编队 |
| 约 75–90 秒 | 大批蓝色妖精由两侧和上方移动 | 蓝色妖精编队 |
| 约 91–107 秒 | 灵梦和露米娅对话 | 双立绘对话演出 |
| 约 108–123 秒 | 关底第一段普通攻击，红色瞄准弹串和蓝色散弹 | 关底普通攻击一 |
| 约 124–139 秒 | 「夜符 Night Bird」立绘与蓝、青色旋转弹 | 符卡一 |
| 约 140–155 秒 | 第二段普通攻击，可见直线光束和绿色弹 | 关底普通攻击二 |
| 约 156–175 秒 | 「境符 Demarcation」立绘与多层环状弹 | 符卡二 |
| 约 176 秒后 | 击破演出与一面结算 | 一面结算画面 |

当前实现保留了三维自由移动与球形碰撞，因此弹幕从录像中的二维图案扩展为朝向玩家的三维锥面。录像中的精确生成帧、弹数、速度、掉落、音乐与原文对话尚未逐帧转录；本表仅用于界定阶段顺序和大致时段。
