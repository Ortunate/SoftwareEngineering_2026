# 当前弹体制作方法

后续按用户 2026-10-28 指示：单个模型显示总面数不超过 1000（包含全部显示层）时，只制作模型与独立外观/几何/碰撞检查，不执行性能相关测试。已有压测工具与结果保留供查阅，不作为这类模型的必跑流程。

当前分支基于 dev/koumakyou，采用原作轮廓优先、纯色与可调光效的低面数三维建模。完整文件清单、碰撞语义、独立查看操作及 raylib 接口见[模型组织与审阅](PROJECTILE_COLLECTION_REVIEW.md)，实测边界见[性能记录](PROJECTILE_COLLECTION_PERFORMANCE.md)。

每类独立分析参考图、比例、亮暗分区和危险体积，保留闭合实体与真实孔洞。顶点遮罩、实例颜色及程序化表面负责风格表现，不把原精灵拉伸成模型贴图。普通敌弹以程序化材质为主；灵梦符札已独立制作纹样贴图并明确正反面 UV，文字与外围对称纹样分别绘制。

保留 Blender 分部件源文件，合并导出一份 glTF 显示网格；碰撞导出保留部件并集与孔洞。泡弹按用户要求采用白光圈内缘对应的闭合体积，光圈内部空隙也属于危险范围。光效参数不改变碰撞。

逐件制作完成整组后统一检查资产、闭合性、法线、面预算、同源几何、探针接触与世界变换；超过 1000 面的模型再按实际需要规划性能验证。每类保留独立人工验收记录，重建后重新验收，自动测试不代签。当前苦无及新增八类、两套敌方激光、灵梦三款和魔理沙四类均通过；泡弹保留原先待最终复验记录。

依赖、缓存和构建产物均隔离在项目目录且不提交。正式资产（.blend、glTF/bin、碰撞数据、元数据）与制作、审阅、测试源码进入版本管理。被否定的样品及其专用工具不继续保留在当前目录，历史由 Git 管理。
