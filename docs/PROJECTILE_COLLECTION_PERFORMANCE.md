# 普通弹体全组性能与检查记录

> 以下是第一轮历史结果，不能作为第二轮几何与材质的性能证明。第二轮重测和变更见 [第二轮修订](PROJECTILE_COLLECTION_REVISION2.md)。原 CSV 已另存 `revision1-results.csv`，当前 `results.csv` 用于第二轮结果。

2026-10-27，在九类新弹体及独立工具全部制作完成后统一测试。硬件为 Intel Core i9-14900HX、NVIDIA GeForce RTX 4090 Laptop GPU；Windows x64、OpenGL 3.3 / NVIDIA 610.62、MinGW 16.2 Release、raylib 5.5。结果只代表本机独立合成通道。

## 检查结论

- 两版苦无和全组资产检查通过。九类新网格及其内核、球壳、火焰均闭合，无退化三角形，满足各自面预算；实体碰撞与最终显示中的对应表面逐三角形匹配。
- 三项 CTest 通过：新十类统一检查、既有苦无渲染/碰撞检查、银色参考碰撞检查。覆盖球体内部、柄孔、世界变换、装饰火焰无碰撞、颜色取模、球壳透明度和内部观察、火球动画、容量、视锥剔除与 GL/线框状态恢复。
- 111 次性能运行完整：18 个短时诊断、31 个完整场景各三次重复。无截图编码参与测量。完整场景为可见 1920×1080、无 MSAA、无垂直同步/限帧，预热 3 秒、采样 10 秒。
- Blender 源文件材质预览的最终完善后，九类显示二进制和碰撞二进制共 18 个文件与完整压测版本的 SHA-256 全部一致；成品绘制通道与压测相同，之后另回归动态线框和独立查看器。

实体/球壳为主的混合场景达到常规目标。极近大泡整帧超过 16.7 ms；三个玉类极近场景也超过 6 ms 的 GPU 阶段目标。全刀弹候选场景超过 2 ms 的 CPU 阶段目标。这些结果保留原数量、效果与碰撞，不能概括成“所有 8192 场景都已达标”。

当前主要边界是大量大泡同时贴近镜头的透明填充，及大量弹体同时进入精确碰撞窄相。后续接入需按真实覆盖率和候选数验证；若必须支持这些极端构成持续运行，应单独优化能量层覆盖/质量档和碰撞候选组织，再按相同输入复测。本轮没有自动降低数量、关闭已测效果或更换简化碰撞。

简化二维圆点基线的整帧 P95 为 1024 发 0.316 ms、4096 发 0.813 ms、8192 发 1.379 ms。它采用 raylib billboard 批处理，三维采用持久缓冲实例绘制，提交方式与材质复杂度不同；不能据此声称三维普遍比二维快。

## 数据与复现

原始 CSV 保存均值/P50/P95/P99、可见数、实际面数/绘制数、各类数量、窄相和命中次数、GPU 样本及跳过数。GPU 时间只覆盖几何绘制通道，CPU 上传单独计时；整帧包含提交窗口。加色透明层不做深度排序，排序开销为零。sprite 绘制数为按默认批容量估计，模型绘制数为实际调用数。

- `output/projectile-review/collection/performance/results.csv`：111 次原始结果。
- 同目录 `hardware.txt`、`summary.md`：硬件及完整汇总。
- `output/projectile-review/collection/asset-checks.json`：整组资产检查。
- `output/projectile-review/collection/`：201 张固定离屏审阅截图。

运行 `Stress-Projectiles.cmd` 可重新执行完整实验；`Review-Projectiles.cmd -Action stress-collection-quick` 只用于短时诊断，不作性能结论。检查与独立操作见 [全组交付说明](PROJECTILE_COLLECTION_REVIEW.md)。

自动测试没有授予美术验收：苦无沿用已通过记录，新九类仍待用户与 leader 人工评估。整场游戏及低配硬件尚需后续接入验证。
