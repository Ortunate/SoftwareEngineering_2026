# 六面 Normal 接入与独立见证

输入为同版本新典的 `ecldata6.ecl` 与两角色 MSG；完整 SHA-256 见 [逐关审阅记录](STAGES_2_6_REFERENCE.md)。运行时只使用显式事件、命名行为和已导入数值，不读取原始 ECL、临时 JSON、解包工具或本机安装目录。

## 出生、对白与开战

本关显式保存 124 次普通出生、两场 Boss、三段 MSG、三次恢复和三次对白信号等待，共 135 行事件。124 次包含四个隐藏的环境位置演出；其余晶体按五种共享配方中的弯曲蓝晶体、弯曲红晶体、横穿蓝环、下降蓝环生成。红蓝初始动画由 `Spawn::initialAnimation` 独立选择，不从攻击反推外观。

道中咲夜在 2493 帧创建并进入 240 帧对白，结束后通知开战。源 2496 等待完整遭遇；实际结束后经过 600 内容帧开始关底对白，不能继续使用固定开局 3096 帧掩盖道中战斗长度。

六面关底 MSG 的 `6` 指令两次放行时间轴，而非整段结束：两角色第一次均在对白第 861 帧，第二次灵梦为 8666 帧、魔理沙为 7866 帧。第一次之后创建蕾米莉亚；第二次之后切入翅膀演出等待；完整对白结束后才正式开战。两角色整段分别为 10704、11106 帧。`WaitDialogueSignal` 以异步 ID 交付这些依赖，`ResumeBoss` 保留两次不同含义的通知，跳句也不能将它们覆盖为同一次交接。

战后 MSG 没有文字，只锁定输入并等待 60 帧；内容通过 `DialogueMinimumDuration` 保留这段静默收尾，不伪造台词。绘制与输入均允许空台词表。道中对白使用 face09a 的咲夜差分，关底表情 2/3 使用 face10a/face10b；场景立绘选择独立于关底符卡立绘。

## Boss 生命与阶段

道中初始 6000 HP；四机体的符卡保留生命分别为 750、1000、1100、1100。非符超时 1020 帧直接退场；生命阈值进入奇术「Eternal Meek」（目录 101），上限 900 帧，准备 120 帧。击破散落二十个道具并掉 Bomb。咲夜两个弹组之间的父时钟冻结、延迟转向及原速率保留分别验证。

关底为九阶段：

| 阶段 | 总 HP / 保留 HP | 内容 | 超时内容帧 |
|---|---|---|---|
| 1 / 2 | 13000 / 1200 | 第一非符 → 天罚「Star of Vanities」（104） | 2700 / 2400 |
| 3 / 4 | 15500 / 1600 | 第二非符 → 冥符「红色冥界」（107） | 2700 / 2400 |
| 5 / 6 | 11000 / 1600 | 第三非符 → 咒诅「弗拉德·采佩什的诅咒」（110） | 2700 / 2400 |
| 7 / 8 | 13000 / 1300 | 化蝠非符 → 红符「Scarlet Shoot」（113） | 3600 / 1800 |
| 9 | 4700 | 「Red Magic」（116） | 7200 |

HP、阈值、机体分支和超时从 `native_combat` 读取。符卡各含 120 帧准备；最终阶段先等待 60 帧才宣告，再进入准备，阶段超时钟从宣告起重置。完整退场另等 60 帧，不以 HP 为零提前结束异步遭遇。

源第二非符把另一计数器设为 90，却继续消费前一符卡的蓄力剩余计数。`PhaseMemory::chargingPulsesLeft` 明确保留这一跨回调状态；默认零时第一等待只有一帧，在蓄力中击破则消费真实剩余脉冲。不能直接“修正”为九十帧或在交接时清零。

## 新典扩展与空间适配

本机 EXE 的扩展函数表为 64 位指针。已核对的入口包括：星阵 `121(7)` RVA `0x35c70`、地雷生成 `121(8)` RVA `0x36270`、地雷解放 `121(9)` RVA `0x36470`，以及最终阶段 Bomb 化蝠回调 `122(10)` RVA `0x36970`。

星阵保留一次随机旋转、两组方向、每组三层八节点、各层长度和起点累计；中性模式逐束比较 48 条光束的出生点、方向、宽度、生效与退场时间。后续从相同节点释放当时配置的弹幕，配方和 rank 的快照语义不变。空间模式直接建立球面节点和局部弦向，不旋转复制同一平面。

地雷仅从仍活动的大弹生成：新典读取 ANM 加载后的逻辑尺寸，6～9 为候选，0～5 不符合。先收集候选位置再生成小球，避免遍历中重入；小球保留一次方向随机读取、零初速和 32 帧显现。解放先读取一次全局旋转，再为静止小弹按到 Boss 的实际距离分配定向加速度，持续 120 帧；三维使用真实 XYZ 距离及局部方向，不回压到 X/Z 平面。

新典 `201` 与普通发射进入 RVA `0x25221`，在 `0x2583b` 区分，`0x2588d` 强制模式 8；模式表 `0x10ce8` 的第八项进入 `0x103e4`。其参数仍为打包弹种/颜色、数量、速度层、首末速度与角区间，实际为随机角度加随机速度。生产用 `RandomAngleSpeed` 与命名锥形弹组表达；中性首发和层数独立对照源参数，空间锥轴可锁定玩家真实 XYZ。

化蝠非符每轮召唤六十只独立演员，禁交互、沿自己的随机轨迹退场。高速空间巡航在新航段前同步规划原点，边界夹取沿实际位移分配高度；禁止沿已被边界挡住的分量继续推进世界对象。长时间池测试覆盖六十秒巡航，防止召唤体出生于回收盒之外后永远占槽。

最终符卡在 Bomb 活动时关闭交互并切入化蝠动画；Bomb 结束后再等待 60 内容帧才恢复。准备期重选姿态时仍须由回调再次关闭姿态与交互，不能在 Bomb 尚未结束时静默恢复本体。超时钟继续，暂停冻结所有逻辑。

项目使用实例 xorshift，不宣称等同原生全局 RNG；空间采样不额外读取攻击随机数。隐藏环境演员保留位置随机顺序和寿命，其原生粒子、翅膀粒子及辅助槽闪光使用项目表现边界，未逐粒复刻。屋顶、红月和薄云为三维装饰；本次仅开放 Normal，Extra、其他难度和原生符卡练习入口仍单独保留未开放状态。

## 验证范围

`tests/stage6_tests.cpp` 独立核对 124 次出生、像素轨迹、普通发弹、对白放行帧、完整/中途结束依赖、四机体生命/超时、九阶段、星阵矩阵、地雷生成/解放、跨阶段蓄力计数、化蝠保护及长时间召唤回收。位置累计误差上限为 `5e-4` 世界单位。120 Hz 行为在 30/60/120/144/240 显示 FPS 下比较位置、动画、弹参数、阶段时钟与后续随机流。

图形 `--stage6-only` 已覆盖两角色整关超时、四机体两场遭遇击破、对白中的入场和演出等待、全部九阶段、光束、召唤、四种 Bomb 的化蝠免疫/恢复、暂停、静默收尾及跨关卸载。两角色整关弹幕峰值均为 1805，演员池和弹池零溢出。连续闯关另以 `--campaign-only` 验证正式结算、异步加载、库存继承和资源释放。

```bash
cmake --build build-debug --target koumakyou koumakyou_tests koumakyou_lifecycle_tests -j 6
ctest --test-dir build-debug --output-on-failure
./build-debug/koumakyou_lifecycle_tests /tmp/stage6-lifecycle --stage6-only
./build-debug/koumakyou_lifecycle_tests /tmp/campaign-lifecycle --campaign-only
```
