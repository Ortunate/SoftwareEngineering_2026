# 苦无独立通道性能记录

2026-10-27，本机实测：Intel Core i9-14900HX，NVIDIA GeForce RTX 4090 Laptop GPU，驱动 610.62 / OpenGL 3.3，Windows x64，MinGW 16.2 Release、raylib 5.5。该机器属于高性能硬件，结果不能推定低端机器也满足目标。

可见 1920×1080 窗口，无 MSAA，关闭垂直同步、帧率限制。13 例，每例预热 3 秒、采样 10 秒、重复 3 次，共 39 次。未最小化窗口。以下取三次重复中**最差的 P95**，单位 ms。

*CPU 列为各阶段 P95 相加的保守值，不是逐帧两阶段之和的 P95。最终精确值以原始 CSV 和自动汇总为准，表格保留三位小数。

普通 8192 场景达到整帧 P95≤16.7 ms、GPU P95≤6 ms、更新与碰撞 CPU≤2 ms 的本机目标。无光效每批 1 次绘制、1,196,032 三角形；开启光效为 2 次绘制、2,392,064 三角形。实例 GPU 缓冲为 768 KiB；调用方实例数组 416 KiB，渲染器内部 CPU 打包数组另占 768 KiB。网格和碰撞结构只保留一份。

二维基线使用 raylib billboard 批处理，三维使用持久缓冲的实例绘制，CPU 提交方式不同；不能根据整帧时间声称三维比二维更快。此实验的运动是合成运动，每帧只对一个球体做离散碰撞，没有关卡脚本、角色、场景、后处理或其他游戏系统。

完整原始分布、每帧候选数量、GPU 样本/跳过数保存在本机 `output/projectile-review/performance/results.csv`，硬件记录见同目录 `hardware.txt`，自动汇总见 `summary.md`。这些运行产物不纳入素材提交。重新运行`tools/windows/Stress-Kunai.cmd` 可复现实验；`-Action stress-quick` 只做短时冒烟检查。

结论：146 面可作为高密度苦无的当前预算，接入完整游戏及验证低端硬件后再确定最终性能承诺。模型美术已于 2026-10-27 经用户与 leader 人工验收通过。
