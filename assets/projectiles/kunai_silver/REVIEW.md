# 银灰苦无 / 首件需求与验收卡

**状态：待用户人工验收。** 目录映射为 Type 4 / C0，本轮只有一个配色。

## 需求

以现实金属苦无的尖叶形刃、握柄和尾环为依据。刃部有中央脊、双斜面和薄倒角；缠柄有体积，深灰蓝织物与银灰钢材区分；尾环是贯通实体。结构不受旧建模分支影响。

整体为标准化约 1 单位长度，本地 +Y 指向刃尖，+Z 为正面。原点位于整体中心附近。未决定正式游戏的世界尺寸或判定倍率。

## 交付

- `kunai_silver.blend`：可编辑几何、UV 和材质，纹理使用相对路径。
- `kunai_silver.gltf`、`kunai_silver.bin`：独立实时模型，不包含游戏逻辑。
- `textures/`：钢材与缠柄两套 2048×2048 PNG；每套有底色、法线、粗糙度、金属度、AO、ORM。
- `collision.bin`：与最终网格同源的七个封闭实体部件。
- `asset.json`：类别、坐标、部件面数及人工验收状态。
- 制作源脚本位于 `tools/projectile_review/create_kunai.py`；修改后可重建全部交付资产。

## 碰撞语义

刃、刃根、柄芯、上下金属箍、缠带、尾环分别封闭，整体取并集。环孔保持空腔；空腔中的小探针不接触，探针大于孔径后会接触环壁。贴图微凹凸不进入碰撞。碰撞显示就是实际查询的三角网格，未用整件包围盒代替。

七个部件之间允许结构性嵌合；并集不重复计接触。BVH 用于最近表面和射线查询，包围盒只作加速。模型变换目前支持平移、旋转和正统一缩放，拒绝非统一缩放。

## 人工验收清单

- [ ] 灰模正面、侧面、背面均像实体苦无，刃脊和厚度合理。
- [ ] 金属反射随观察/光源变化，没有不自然的分段高光或塑料感。
- [ ] 缠柄有几何层次和织物感，不是拉伸图片或涂黑的圆柱。
- [ ] 尾环圆润、连接自然、孔洞真正贯通。
- [ ] 纹理没有可见拉伸、破损接缝或固定的假高光。
- [ ] 碰撞贴合刃、柄、环壁；Hole 探针可穿孔，Ring 探针正常接触。
- [ ] 中性、深色、明亮背景下均可辨认，放大后无明显破面。
