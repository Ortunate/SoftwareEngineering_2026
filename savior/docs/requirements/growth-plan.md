# 三年成长型练习设计（2.0）

日期：2026-09-20。对应课程第2题“儿童学习”的持续三年使用目标。这里的三年指从一年级基础逐步扩展到三年级整数计算场景，不是已经开展三年实测，也不是完整数学课程。

## 使用路线与范围

| 预设 | 练习内容 | 使用方式 |
| --- | --- | --- |
| 一年级·基础 | 20以内加减 | 建立数的分合与基础计算习惯；可自定义降至10以内 |
| 一年级·提升 | 100以内加减 | 按需筛选进位、退位或不进退位 |
| 二年级·表内 | 表内乘法与整除 | 巩固乘法口诀及乘除关系 |
| 二年级·两步 | 两步四则混合 | 先乘除后加减，同级从左到右 |
| 三年级·多位数 | 千以内加减、多位数乘除一位数 | 可用草稿纸或打印笔算 |
| 三年级·综合 | 三步、括号、多位数计算 | 结合计算步骤理解运算顺序 |
| 数域进阶 | 万以内整数运算 | 按实际能力选练，不强制解锁 |
| 课外拓展·负数 | 正负整数与两步加减 | 家长指导下选学，不作为低年级必学内容 |

预设为产品组织方式，不承诺与任何教材的学期安排一一对应。参考[教育部《义务教育数学课程标准（2022年版）》](https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220420582346895190.pdf)，将基础数与运算逐步扩展；实际起点与升级时机仍需家长、教师根据学习情况调整。

## 新增可验收需求

| 编号 | 规则 | 证据 |
| --- | --- | --- |
| FR-20 | 六种数域10/20/50/100/1000/10000；八个阶段；自定义一步、两步、三步和括号 | T20、人工G01 |
| FR-21 | 正负整数可选；操作数、每个中间结果和最终结果绝对值均不超所选范围 | T20–T22 |
| FR-22 | 表内乘除或多位数乘除一位数；不除零、不出非整除、不产生小数 | T20–T21 |
| FR-23 | 批改后展示按执行顺序计算的步骤，结果与判题使用同一结构化算式 | T21、人工G02 |
| FR-24 | 高级错题保存结构及原配置；复习保留原题并尽量生成同类变式 | T24 |
| FR-25 | 预设阶段累计次数、题量、正确题数独立于200次明细；最近3次每次至少10题且正确率≥90%提示可进阶 | T25、人工G03 |
| FR-26 | 读取旧版数据并迁移至schema 2；导出包含新旧题及阶段累计；格式错误不替换 | T24、人工G04 |

负数开关开启后生成题至少包含负操作数或负中间结果。表内乘数的绝对值为1–9；多位数模式右乘数及除数绝对值为1–9，商为整数。高级进退位筛选检查各位，仅用于非负一步加减。复合和负数模式自动禁用进退位筛选。

## 练习、评价与长期使用

默认每套30题，允许5–50题。三年中可按掌握情况反复练习并调整题型，不采用固定日期强迫升阶。自定义和错题复习不计入预设阶段累计，仍进入练习历史、错题和题型统计。旧数据未记录阶段，迁移时不猜测归属。

原有基础题保持既定计时规则。高级题按运算节点数计算参考时间：每步通常18秒，含负数20秒，千以内30秒，万以内45秒；数域规则优先。仍先检查作答完整性和准确率，纸笔记录不做速度判断。这些是透明的产品初值，不是教育测评标准。

详细历史保留200次、错题保留2000道；阶段累计不会因明细淘汰而删除。定期导出备份，换设备时手工迁移；清空浏览器数据会丢失未备份记录。数据仍只在单个浏览器保存，容量不足时明确提示并允许导出，不宣称云端永久保存。

## 边界与后续验证

本版本增加了可支撑长期分阶段练习的题型与记录机制，但没有带余数除法、分数、小数、应用题、几何、多孩子档案或教师班级系统。负数拓展不能替代这些内容，也不能单凭题目更难就证明教育效果。

课程提交可以说明“三年成长型练习已形成可执行路线和实现”，不能写“已验证连续使用三年”。后续需要真实家庭试用、教师审阅各阶段难度、记录使用频率和反馈，验证题型安排是否满足实际需求。
