# Stage 1 新典数据对照

本分支按用户确认的“保留 3D 操作，严格保留新典波次、轨迹和弹幕结构”实现 Normal 灵梦一面。此前依靠录像概括的波次与三维锥面技能已退出实际关卡；旧 FairyEnemy、DarkFairyEnemy、OrbEnemy 仅保留为独立测试/调试演员。

## 数据来源与复现

通过 `output/th06nc-reference.app` 连接本机运行的参考游戏，用 computer use 确认菜单与 Normal 开局；用户的 BetterCapture 录像用于对照画面。流程数据直接读取本机新典安装目录：

- `th06ST.dat/ecldata1.ecl`：38 个子程序，筛选 Normal 后 570 条指令，222 次杂鱼出生请求。
- `msg1.dat` 与 `localization.msgpack` 的 zh-CN 条目：15 句战前对话、2 句战后独白、逐句等待时间、双行延迟和音乐切换。
- `frame.anm`、`frame_stage1.anm` 及对应 zh-CN DDS：背景图集、场地边框、左侧一面题签与右侧花纹/标志。
- `th06CM.dat` / `th06ST.dat` 的 25 套战斗 DDS/ANM：原始角色、弹幕、道具、自机及特效；文件与接口见 `NATIVE_BATTLE_ASSETS.md`。
- `th06IN.dat` 的 WAV：菜单及战斗音效，保留原始波形。

输入文件 SHA-256：

```text
ecldata1.ecl be9e49fe6f1c9fcbca858d335773bc16b1a89ae25083b60d1cb5ab33814dd2f3
msg1.dat     968f8bff0c386e4f9d18f116a52b25b0a3137d098bced43280a8e52a84037ec9
```

解包使用 [thdat-nc](https://github.com/Renko6626/thdat-nc)，反编译使用 [thtk](https://github.com/thpatch/thtk) 的 `thecl -d 6` 与 `thmsg -d 6`。像素/帧指令的语义对照 [th06 引擎还原](https://github.com/GensokyoClub/th06)。临时工具、游戏原始包与解包缓存不入库。已转换的只读指令与出生表是运行时源码数据；重新导入：

```bash
thecl -d 6 ecldata1.ecl stage1.ecl.txt
python3 tools/import_stage1_reference.py stage1.ecl.txt
```

`!E/N/H/L` 为持续生效的难度掩码；不能只过滤带前缀的单行。跳转标签转换为子程序内指令索引，时间仍为原始 60 Hz 帧。

## 3D 约定与呈现

原作 384×448 像素运动统一以 `20/448` 世界单位/像素投影到 X/Z：X 居中，原作 Y=0…448 对应世界 Z=+10…-10，敌人从 +Z 远端向玩家推进、转弯与退场。出生点原作 Y=-32 对应世界 Z≈+11.43；原作 Z=0 对应世界 Y=0，与玩家初始高度一致，原作 Z 正方向映射到世界 -Y。原轨迹、扇形角距、环相位、速度层与弹数保留，延迟转向绕世界 Y 轴旋转；每轮发弹增加朝玩家所在高度的 Y 速度，整轮锁定高度坡度，不额外增加弹数。原作散落道具也沿 X/Z 展开。玩家继续使用 6DoF 移动、转向、原项目射击与球形/光束胶囊碰撞。

原 HP 和阶段阈值统一除以 25，适配当前玩家伤害；符卡射击伤害再缩小至七分之一。独立演员使用可重放随机种子，保留随机范围与分支结构，但不保证与 Wine 游戏共享同一随机序列。道具生成遵循出生的 item 字段与 ins_119；3D 道具仍沿 Z 上抛、下落、吸取。基础点数值、擦弹判定、玩家火力与最终结算沿用本项目三维玩法，分数不是新典逐帧复算结果。

界面按原作 1920×1080 等比居中，场地视口为 `(532,40,856,1002)`，宽窄窗口留边。原边框/题签/侧栏纹理、分数、残机、Bomb、Power、Graze、点数、Enemy 血条、阶段计时、符卡名、双行对话、Boss 名牌与战后 BONUS 均使用同一布局。战斗精灵直接读取原始 DDS/ANM，恢复待机、移动、收势、弹幕显现和击破动画；三维场景保持项目空间约定。对话现代立绘按原作表情编号切换：灵梦 a0/a1/b0/b1/c0/c1 对应 0–5，露米娅 a0/a1/b0/b1 对应 0–3；未发言的一方保留最近一句表情。半身与全身构图通过素材清单的 dialogueCrop 适配。

## 验证

核心测试校验 222 次出生请求、1882/5092 帧时序、镜像航线、Normal Sub3 七向弹与 Sub4 无攻击、道中首轮 48 弹、关底首轮十速度层、六光束、34 发双环及显现/延迟转向参数。掉落测试校验每三次轮换与 ins_119 的五道具结构。

隐藏图形窗口按 60 Hz 无攻击推进灵梦整关，经过原始对话等待、Boss 超时退场及十秒结算，在约 311.05 秒完成；该值不应与录像中快速击破和按 Z 推进的 187 秒混同。另验证两张符卡练习的捕获/超时差异、暂停冻结、Bomb 清弹、资源释放与成绩保存规则，并导出 16:9、4:3、21:9 和真实 Retina framebuffer 的检查图。对白专项额外覆盖两位自机战前／战后每句的横竖屏立绘、差分边界与实际键鼠输入保护。
