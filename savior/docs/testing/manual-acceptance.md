# 手动验收清单

请用户在本地浏览器操作，不需要 Computer Use。现有用户已报告完成过30题试用，但以下ver1.0新增行为尚无逐项验收结果。

## 开始前

1. 若有需要保留的学习记录，先在「数据与帮助」导出 JSON。
2. 运行 `node savior/scripts/serve.cjs`，打开 http://127.0.0.1:4173；现有页面刷新即可加载新版本。未提交答案刷新会丢失。
3. 记录操作系统、浏览器版本、屏幕大小和测试日期。请使用同一地址，避免将来源隔离误认为数据丢失。
