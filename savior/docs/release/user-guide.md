# 小芽口算用户手册

## 开始练习

双击 `index.html` 即可使用。推荐在仓库根目录执行 `node savior/scripts/serve.cjs` 后访问 http://127.0.0.1:4173，长期使用保持同一浏览器和地址。

今日练习中选择起步、进阶或综合档位，或自行设置数值范围、题量、进退位和运算。默认30题，最少5题、最多50题。点击生成练习后开始计时。

题目范围同时约束操作数和答案；乘法是表内乘法，除法只包含正整数整除。题库不足时减少题量或放宽条件。

## 作答与快捷键

- 填写非负整数答案；0 是有效答案。
- **Tab** 前往下一题，**Shift+Tab** 返回上一题。在最后一题按Tab将进入提交按钮等后续控件。
- 在答案框内按 **Enter** 提交批改；也可点击「完成并批改」。留空题会先询问，确认后按错误记录。
- 切换到其他应用页面或隐藏浏览器标签时自动暂停计时，回来继续；确认弹窗和打印期间暂停。
- 提交后计时停止，显示标准答案及本次表现。未提交题单不保存草稿，刷新可能丢失。

## 如何理解本次表现

准确率按正确题数除以总题数计算，不因为更快或更慢加减分。平均每题用时包含检查答案的时间。

有空题时先提示补练；准确率低于90%时先巩固正确性。满足全部作答、准确率至少90%、不少于5题且平均不少于1秒时，才参考题型用时给出节奏建议。可以展开「计时与判断规则」查看具体阈值。这不是教育诊断，也不用于不同孩子排名。

老版本记录仍可查看，但采用旧计时口径，不评价速度。题单打印过后可能用于纸笔，录入速度不能代表计算速度，因此同样不评价。

## 错题与历史

错题花园显示待巩固与已巩固题目。一次复习最多10道原题，再配同类型变式。原题连续答对两次后标记已巩固；以后答错会重新进入待巩固。

成长记录保存最近200次提交，可展开查看逐题答案与用时。题型条形图显示当前保留记录的正确数/总数，不是全学期永久统计。

## 纸笔练习

在题单页面点击打印，选择A4。空白题单在前，参考答案另起页；由家长核对。若希望保存纸笔练习结果，应保持本次题单打开，将孩子写下的答案录入后提交。当前不支持拍照识别。

## 保存、迁移与恢复

记录仅在当前浏览器保存，无账号同步。换浏览器、端口、网址或清除站点数据，记录不会自动跟随。在数据与帮助中导出JSON；在目标环境导入前校验文件，确认后替换该环境记录。

存储不可用时仍可在当前页面练习，但刷新前应导出备份。建议一个标签页练习，避免多标签相互覆盖。

清空全部记录需确认，不能从应用内撤销；先备份可在清空后恢复。当前按一个孩子的数据集设计。

## 常见问题

| 问题 | 处理 |
| --- | --- |
| 页面更新后没有计时器 | 先提交或放弃未完成题单，再刷新；必要时Ctrl+F5 |
| 样式没有加载或资源404 | 确认本地服务为最新版本并重启；不能只复制HTML，需保留src目录 |
| 端口4173占用 | 停止旧服务，或设置PORT使用其他端口；注意不同地址的记录隔离 |
| 只有少量题可出 | 进退位、运算与小范围交集太小，放宽条件或减少题量 |
| 学习记录不见了 | 核对浏览器和完整访问地址，通过JSON备份恢复 |
| 导入失败 | 使用本应用导出的完整JSON，不编辑题目、答案和状态；上限5MB |
| 打印取消后显示纸笔记录 | 为避免误用录入时间，打开过打印就不再给速度评价 |
