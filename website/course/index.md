## 发布检查

网站提供软件介绍、截图、使用说明与准确获取方法，并应至少保留一个月。当前实机截图、公开运行包、正式上线日期及用户反馈仍待补充；网站可浏览不表示全部课程材料已完成。

课程教案要求在 Gitee 记录过程；本项目按当前方案使用 GitHub 和单一网站。平台适用性需在课程提交时核实，本网站不声称已满足平台要求。
