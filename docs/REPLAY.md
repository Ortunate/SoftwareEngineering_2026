# Replay 使用说明

正常关卡流程结束后询问保存 Replay；练习结果页可以选择“保存 Replay”，未保存便重试或返回时询问一次。选择是后输入名称，Enter 保存，Esc 返回询问。保存询问直接复用暂停界面的浮窗、纵向文字按钮、选中动效和命中布局；命名和字符选择使用现有 UI 组件，支持键鼠操作。命名时字母及空格只输入文字，Tab 或方向键选择按钮，Enter 激活按钮，Backspace 删除，Esc 返回询问。Windows 命名时临时启用输入法；其他平台仍可使用屏幕字符选择。最多 32 个 Unicode 字符，名称不决定文件路径；未收录字形由字体回退显示。没有有效待保存录像或已保存时，结果页保存项禁用；拒绝后可手动重开保存，失败保留名称和录像以便重试。中途退出、重试、调试与预览不保存，未来续关后取消保存资格。

录像文件位于启动目录的 `replays/`。目录没有 `.krep` 普通文件时，主菜单 Replay 置灰且键鼠跳过；仅有损坏、旧版或不兼容文件仍允许进入列表查看原因。返回菜单、保存成功、窗口聚焦和主菜单每秒刷新目录状态。主菜单 Replay 选择播放，播放本身不更改玩家设置、最高分和符卡记录。

| 快捷键 | 功能 |
| --- | --- |
| 当前配置的 Bomb 键 | 暂停/继续；键盘、鼠标绑定均支持，暂停期间仍可观察 |
| 左/右 | 后退/前进 5 秒 |
| Shift + 左/右 | 后退/前进 30 秒 |
| Home / End | 开头/结尾 |
| [ / ] / 1 | 减速/加速/恢复 1 倍，支持 0.25/0.5/1/2/4 倍 |
| V / R | 第一人称、第三人称、自由视角循环 / 重置相机 |
| 鼠标 / 滚轮 | 观察方向 / 第三人称距离 |
| 已配置的移动 / 升降 / 低速键 | 自由视角平移 / 升降 / 降低移动速度 |
| Esc | 返回录像列表 |

底部播放栏展示当前状态、进度、时间、倍速、视角和操作提示。播放到末尾停留，可继续倒带。倒带从当前已实现的单关入口重算，显示定位中；每帧限制工作量，连续请求以最新目标为准。暂停、非 1 倍和定位时静音，恢复正常播放时对齐 BGM；跳过的音效不会补播。观察镜头不改变玩家输入和判定。第三人称和自由视角显示现有灵梦/魔理沙角色动画贴图。

可用 `koumakyou --replay <文件>` 直接播放；`--capture-replay <文件> <PNG路径> <秒数> <视角0/1/2>` 用于隐藏窗口导出画面。

协议及未来四难度、六面、Extra 的接入约定见 [v2 协议](REPLAY_PROTOCOL.md)。当前只实现 Normal 一面；旧版或尚未实现内容仍保留文件，不允许错误回退播放。

本轮按用户要求未新增或修改单元测试。既有 Replay 测试预期自动保存、v1 和结束自动返回列表，与新版不兼容，不能将旧二进制的结果作为新版验收证据。核心与 UI 的既有检查可独立运行。此前默认 framebuffer 像素断言失败已在未修改的 95d2689 复现。

已封存录像在退场期间从暂停菜单返回或重试，也先询问保存；战斗中途退出仍直接丢弃。播放栏、录像列表和保存弹窗均复用现有通用组件，绘制不访问文件系统。

第三人称和自由视角使用本机 Option 中的鼠标灵敏度（原有基础弧度/像素乘灵敏度百分比），不使用录像内的鼠标设置。第三人称鼠标水平移动对应相机同向环绕；自由视角右向量遵循玩家坐标约定，左右移动与第一人称一致。观察设置及输入不写入录像，也不改变录像中的自机轨迹。
