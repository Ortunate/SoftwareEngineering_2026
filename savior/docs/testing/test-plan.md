## 人工验收

详见 [manual-acceptance.md](manual-acceptance.md)。人工覆盖 DOM 操作、真实浏览器存储、键盘、计时可见性事件、打印分页、360px 布局、离线和公开访问。代码测试不能证明这些均正常。

## 性能验证

核心出题测试覆盖 4,000 道生成结果，证明边界与算法可重复，不代表浏览器性能基准。实际性能验收在目标设备记录浏览器版本、配置、50题生成和提交的响应，目标均不超过1秒；界面计时按秒显示，不以测试执行时间替代实际渲染时间。

## 完成标准

自动化测试全部通过；主要浏览器人工流程无阻断错误；备份恢复与打印通过；发布地址外部可访问后，FR-16 才能标记完成。用户反馈需真实留存。人工测试结果尚未提供时不得写成全部验收通过。
