# 录像、音乐与设置

## Replay

主线、Extra、关卡练习和可玩符卡练习结束后，可按提示保存并命名录像。中途退出、重试、调试与预览不保存有效录像。

从主菜单 Replay 进入列表，支持暂停、定位、倍速，以及第一人称、第三人称和自由观察。播放不修改玩家成绩与解锁记录；录像仅支持相同构建。

| 操作 | 功能 |
| --- | --- |
| 当前 Bomb 键 | 暂停／继续 |
| 左／右 | 后退／前进 5 秒 |
| Shift + 左／右 | 后退／前进 30 秒 |
| Home / End | 开头／结尾 |
| [ / ] / 1 | 减速／加速／恢复 1 倍 |
| V / R | 切换视角／重置相机 |
| Esc | 返回录像列表 |

文件兼容性、保存失败与完整操作见 [Replay 使用说明](/reference/REPLAY)。

## Music Room

现有 17 首 BGM 按标题、主线各关道中与 Boss、Extra 和结局排序。每页 6 首，左右方向键或 A / D 翻页，上下方向键或 W / S 以及滚轮选择，确认试听。X / Esc / 右键返回。

## Option 与按键

设置入口提供 FPS 上限、音量、鼠标灵敏度和键鼠绑定等选项。设置持久化规则见 [设置说明](/reference/SETTINGS_UPDATE)。不要将游戏截图中的按键提示当作所有玩家都相同的绑定。
