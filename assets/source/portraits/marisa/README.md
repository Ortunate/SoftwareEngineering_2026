# 魔理沙完整立绘重绘

本批通过内置 image_gen 重绘新典原始魔理沙六张对话差分，以项目已认可的骑扫帚现代立绘统一人物和画风；原始姿势、表情及符号逐张保留。完整提示词、修正提示、原始坐标、输出尺寸及 SHA-256 在 `prompts.json`。

原始文件来自本机 `th06CM.dat` 的 `face01a/b/c.anm` 和对应 `_4k.dds`。每个 ANM 含两个精灵，逻辑图集为 2048×2048，精灵区域为 `(1,1,620,1024)` 与 `(622,1,620,1024)`；按 4096×4096 DDS 的 2 倍坐标无缩放裁出，原始 PNG 保存在 `originals/`，不改写参考游戏。

| 原典表情索引 | 运行时 PNG（相对 assets/runtime/common/portraits/marisa） | 动作与表情 |
|---|---|---|
| 0 | `face01a_0.png` | 侧倾、双手低垂，睁眼小幅微笑 |
| 1 | `face01a_1.png` | 直立提围裙，睁眼小幅微笑；用于选人后层 |
| 2 | `face01b_0.png` | 侧倾、双手低垂，闭眼含笑、脸红 |
| 3 | `face01b_1.png` | 直立提围裙，闭眼开怀笑 |
| 4 | `face01c_0.png` | 侧倾、双手低垂，闭眼噘嘴、红色生气符号 |
| 5 | `face01c_1.png` | 直立提围裙，闭眼局促、浅蓝汗滴 |

六张均为独立透明 RGBA 全身 PNG，保留原可见帽子、服装、双脚及手势，不二次放大；表情修改以对应现代姿势为底图。原图的图集黑白块与背景杂边不属于角色，重绘时去除。成品的黑裙和黑帽仍保留。

连同 `assets/runtime/common/spell_practice/marisa_modern.png` 的骑扫帚选人图，项目现有七张现代魔理沙立绘覆盖六张对话差分与选人前景。原选人后层 `slpl01a` 与 `face01a_1` 是同一提围裙姿势，现用 `face01a_1` 重绘版的上部替换，来源映射见 `prompts.json` 的 `menu_reuse`。两层保持不同姿势，灵梦后层不变。

本批只将差分加入素材库，并替换已存在的选人后层；尚未开放的魔理沙实战与对话路线仍保持原来的门禁。未使用的差分不会在通用资源初始化时全部加载，后续关卡可按原典表情索引从上述目录引用。
