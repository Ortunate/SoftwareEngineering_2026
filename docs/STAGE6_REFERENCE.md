本机 EXE 的扩展函数表为 64 位指针。已核对的入口包括：星阵 `121(7)` RVA `0x35c70`、地雷生成 `121(8)` RVA `0x36270`、地雷解放 `121(9)` RVA `0x36470`，以及最终阶段 Bomb 化蝠回调 `122(10)` RVA `0x36970`、逐弹随机解放 `121(11)` RVA `0x36710`。
