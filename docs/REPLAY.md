# Replay 使用说明

主线和 Extra 通关后先登记成绩；失败结果页返回主菜单时也先进入分数选存。完成或放弃分数登记后，再询问是否保存 Demo（Replay）。练习结果页可选择“保存 Replay”，未保存便重试或返回时询问一次；战斗中途退出、调试与预览不保存，续关录像不能保存。

选择保存后进入 60 个固定槽位，先选槽、再命名；已有槽必须确认覆盖，默认选择“否”。命名取消返回选槽，选槽取消返回保存询问。名称与成绩共用最近成功保存的名字：首次为空，成绩命名后 Demo 默认用该名字，单独保存 Demo 也更新下次成绩及 Demo 的初值，重启后保留。写入失败保留草稿与旧录像供重试。

两种命名复用 `ui::NameEntry`，统一 1～8 个可打印 ASCII 字符，不能全为空格；输入框显示八格，屏幕字符表覆盖大小写、数字、符号及空格。字母和空格只输入文字，方向键按行列移动、Tab 顺序选按钮，Enter/左键激活，Backspace 删除，Ctrl+A 重新输入，Esc/右键返回。忽略非 ASCII 输入。取消或失败不覆盖最近成功保存的默认名；这些失败处理是本项目约定，原作参考边界见 [名称与列表参考](NAME_REPLAY_REFERENCE.md)。

录像文件位于启动目录的 `replays/`，槽位使用 `th6_01.krep`～`th6_60.krep`，名称不决定路径；覆盖先完整写入临时文件，再原子替换目标。旧时间戳文件作为 60 槽后的附加页保留，不自动迁移或覆盖，原有 UTF-8 长名称仍可读取。目录没有 `.krep` 普通文件时，主菜单 Replay 置灰且键鼠跳过；仅有损坏、旧版或不兼容文件仍允许进入列表查看原因。返回菜单、保存成功、窗口聚焦和主菜单每秒刷新目录状态。主菜单 Replay 选择播放，播放本身不更改玩家设置、最高分和符卡记录。

| 快捷键 | 功能 |
| --- | --- |
| 当前配置的 Bomb 键 | 暂停/继续；键盘、鼠标绑定均支持，暂停期间仍可观察 |
| 左/右 | 后退/前进 5 秒 |
| Shift + 左/右 | 后退/前进 30 秒 |
| Home / End | 开头/结尾 |
| [ / ] / 1 | 减速/加速/恢复 1 倍，支持 0.25/0.5/1/2/4 倍 |
| V / R | 第一人称、第三人称、自由视角循环 / 重置相机 |
| 鼠标 / 滚轮 | 观察方向 / 第三人称距离 |
| 已配置的移动 / 升降 / 低速键 | 自由视角平移 / 升降 / 降低移动速度 |
| Esc | 返回录像列表 |

底部播放栏展示当前状态、进度、时间、倍速、视角和操作提示。播放到末尾停留，可继续倒带。倒带从录像首关（或所选练习入口）重算，跨关沿用原有加载和库存交接，显示定位中；每帧限制工作量，连续请求以最新目标为准。暂停、非 1 倍和定位时静音，恢复正常播放时对齐 BGM；跳过的音效不会补播。观察镜头不改变玩家输入和判定。第三人称和自由视角显示现有灵梦/魔理沙角色动画贴图。

可用 `koumakyou --replay <文件>` 直接播放；`--capture-replay <文件> <PNG路径> <秒数> <视角0/1/2>` 用于隐藏窗口导出画面。

协议见 [v2 协议](REPLAY_PROTOCOL.md)。Start 支持 Easy/Normal/Hard/Lunatic：Easy 到五面，其余到六面；Extra Start 使用独立 Extra 路线。Practice Start 每个可玩关卡单独录制，Spell Practice 每张可玩符卡单独录制（包含 Extra）。符卡回放不要求本机已有解锁记录，普通练习启动仍遵守解锁门禁。未知或不兼容内容保留文件并拒绝播放。

已封存录像在退场期间从暂停菜单返回或重试，也先询问保存；战斗中途退出仍直接丢弃。播放栏、录像列表和保存弹窗均复用现有通用组件，绘制不访问文件系统。

第三人称和自由视角使用本机 Option 中的鼠标灵敏度（原有基础弧度/像素乘灵敏度百分比），不使用录像内的鼠标设置。第三人称鼠标水平移动对应相机同向环绕；自由视角右向量遵循玩家坐标约定，左右移动与第一人称一致。观察设置及输入不写入录像，也不改变录像中的自机轨迹。

Replay 播放与保存选槽共用表格，列为 No.、NAME、DATE、SHOT、RANK、SCORE、STAGE；空槽显示占位符，损坏或不兼容项保留并显示原因。横屏每页15槽，竖屏每页8槽（每槽两行），上下/滚轮选槽，左右方向及页面两侧居中的公用箭头翻页。普通通关显示 ALL，未通关显示到达关卡，Extra 显示 EX，符卡练习显示 S 加原典编号；底部说明区分 Start、Extra Start、整关及符卡练习。

日期来自文件内开局时刻（UTC），旧 v2 缺失时间时显示占位符，不从文件名或修改时间推测。摘要读取按需加载头部；确认播放前仍完整读取并检查校验和、模拟版本及入口资格。绘制只使用缓存，不访问文件系统；不兼容文件不能播放。

## 与完整关卡分支的衔接

战斗仍按固定 120 Hz 补算，录像逐步输入是显示更新的快照；鼠标增量和 Bomb 边沿先进入同一缓存，不能在回放时再次读取实时键鼠。辅助瞄准开关随输入记录，观察相机不进入模拟。

主线及 Extra 在整轮胜负确定时封存；主线中途结算和切关仍连续录制，异步加载时间不进入输入流。每关入口记录真实库存、火力、rank、累计分数及固定掉落种子；播放校验片段出口和下一关入口，异常即停止。整关练习在 StageClear 奖励固定后封存，符卡练习在所选符卡结算时封存。回放停在战斗终点，不推进结局或写成绩。播放退出恢复原关卡、难度和符卡选择。

`koumakyou_replay_tests` 检查格式往返、摘要、槽位发布/覆盖保护、辅助瞄准输入和不支持/损坏入口拒绝。`koumakyou_postgame_lifecycle_tests <目录> --names-only` 覆盖八字符输入、共享名称、分数→Demo流程、覆盖确认、旧文件附加页及横竖屏表格。`koumakyou_lifecycle_tests <前缀> --replay-only` 对照混合显示步长的短轨迹、摄像机方向、分数、实际弹位置、各模式入口恢复、跨关片段继承与跨关倒带；短轨迹不代替完整通关终局的录像验收。
