# UI 选择与过渡效果

通过 computer use 操作本机 `th06nc-reference.app`，参照新典标题的红色选中项、太极纹样、细线星芒，以及 Option 页的金色文字光晕和当前数值强调，保留本项目的重绘背景与响应式布局。

- 标题选择使用红色渐变、轻微横移、旋转太极、呼吸亮度与流动星芒，移除整行浅色块。
- 太极游标采用连续 S 形阴阳鱼、对称鱼眼、朱红细双圈和四处短刻线；主体半径为 9 个设计像素，色带独立填充，缩放和淡出时保持轮廓清楚。
- 选项、开局、音乐、按键设置和暂停使用相同的强调渐变；设置数值和确认操作有短促闪光，进场文字错开滑入，开局立绘同时淡入。
- 深色菜单背景的花纹和环纹缓慢转动，背景从进场首帧起填满窗口，文字与立绘保留淡入。移动、确认、取消沿用现有音效，补齐 FPS 和按键设置的反馈。

`ui_motion.hpp` 使用秒为单位的独立展示时钟，在输入处理之后推进；选择不等待动画结束。页内行号最多 16 个，页面和设置子页切换时重置强调，连续切换从当前强度继续渐变。`ui_effects.hpp` 绘制光晕和装饰，不持有纹理，也不改变文字度量。绘制位移只影响视觉，鼠标命中仍使用 `menu_layout.hpp` 中的最终矩形，静止鼠标不会抢回键盘选择。

验证包括 30/240 FPS 下同时间长度的效果一致性、快速选择后切页清除残影，以及隐藏窗口中的原设置保存、箭头命中、按键录入与六种窗口比例回归。`koumakyou_settings_ui_tests` 额外输出进场和选择中间帧，供检查过渡过程。

## 全界面窗口适配

窗口不再限制为至少 900×620。`Canvas` 接收实际窗口逻辑尺寸及页面设计尺寸；二级页的 `PageCanvas` 使用 `Canvas::Full`，将位置和面板矩形按窗口双轴比例铺满，字号、圆形纹饰和立绘保持等比。最小化返回零尺寸时按 1 像素保护缩放计算。连续改变窗口尺寸不会重置菜单选择或播放进场动画。

- 首页自动进场，取消 `Press Z / Enter` 等待页，菜单最后显示，保留全窗口背景和窄屏重排；首页底部不再绘制操作说明、关卡描述和来源提示栏，原作信息仍可在制作信息页查看。
- 首页背景重绘为 `common/title_layers/` 下的红月、神社、灵梦三张透明纹理，人物层已单独修正手部，托腮左手改为掌面轻托下颌。红月按月球本身的中心对齐字标中心，位于标题后方；神社和灵梦独立定位、等比缩放并使用 mipmap，窄屏限制人物轮廓宽度。原合成图仅在图层缺失时回退。完整提示记录见 `TITLE_BACKGROUND_LAYERS.md`。
- 首页字标使用 `common/title_logo_yidian.png` 透明素材，参照用户提供的新典标题，突出朱红“红”字，包含英文副标题、饰线和本项目的“异典”题签。字标随窗口居中等比缩放，宽屏使用菜单左侧空间放大，窄屏限制在菜单首行上方；缺失时回退到居中加粗文字。`AssetManager` 持有其纹理，随通用资源释放。
- 选项、开局选择、音乐、成绩和制作信息在方形/竖屏下切换为 760×1100 的纵向设计；选项标签、数值及箭头保留独立空间，开局立绘与选择卡片上下排列。
- 选项、改键、开局、音乐、成绩和制作信息复用 `menu_page.hpp` 的全窗口渐变、花纹、回纹边框及操作按钮；选项与改键还共用页眉、题签和页脚。Key Bindings 不再绘制独立背景模板，列表及弹窗位置仍由 `BindingsLayout` 负责。
- 暂停、结算及临时提示共用 `OverlayLayout`；暂停行的绘制/命中使用同一个矩形，统计分两行，长提示按可用宽度缩小字号。
- 战斗视口、HUD、原文对话、题签和符卡立绘保留原作 1920×1080 比例并等比居中，避免窄窗口拉伸场地或改变弹幕呈现。

核心布局检查覆盖 1×1、320×180、320×240、390×844、900×900、1600×400、180×900、3840×2160 的交互矩形和 3D 视口边界。图形集成测试在五种窗口大小下输出 19 种界面，并回放缩放后的改键录入、返回按钮及暂停继续按钮；正式一面流程仍由生命周期集成测试覆盖。

二级页另检查设计画布的四边与窗口完全重合，并读取截图顶部、底部的渐变颜色，防止等比居中留边或 Key Bindings 回退到另一套底色。

## 首页启动动画

`title_entrance.hpp` 使用独立的秒制展示时钟。五段依次在 0～0.55 秒（红月）、0.55～1.0 秒（标题）、1.0～1.55 秒（神社）、1.55～2.15 秒（灵梦）、2.15～2.6 秒（菜单）进场；前一段完成后下一段开始。月球围绕真实中心轻微放大，标题上移，神社与灵梦从左侧滑入，菜单按行错开但在 2.6 秒统一完成，透明度使用缓出曲线。绘制仍按红月、神社、灵梦、标题的遮挡关系合成，不能按开始时间改变深度顺序。

完整动画结束前屏蔽首页键盘和鼠标操作，不缓存确认。结束后 Z/Enter 直接进入开局选择，不需要额外确认一次；离开后返回不重播，也不强制重置鼠标位置。窗口改变只调整布局，不重置时钟。核心测试验证五段顺序和 30/240 FPS 下的同时间进度；图形测试输出七个时刻的截图并检查动画中的键鼠门禁、结束后确认及返回行为。

## 按键设置汉化

按键设置入口、页眉、10 项操作、恢复/返回按钮、选择与录入提示均使用中文；左下角红色题签保留英文 `Key Bindings`。鼠标按键、方向键、空格、回车及特殊键名同时汉化；字母、数字、F1～F12 与 Shift/Ctrl/Alt 等实体键帽标识保留，数字小键盘单独标注。默认低速移动使用鼠标右键、射击使用鼠标左键、符卡使用 F、暂停使用 P，不再提供备用键。配置以整数键码保存，version=4 将旧默认主键升级到新布局并移除备用字段，其他自定义主键保留。中文字体子集随界面文字重建，图形测试检查实际加载的字体覆盖所有操作和合法键名。
