# 1.0.1 多分辨率与缩放验收

反馈环境已确认为 Windows 11 / Chrome，不是最初推测的 macOS。尚未提供具体错位位置或截图，因此本轮针对代码中可见的固定尺寸和挤压风险改进，不声称已复现或修复某个真实设备上的确定缺陷。

按用户要求不使用 Computer Use 或其他浏览器自动化。本清单由组员手动执行。此前填写的 `manual-acceptance.md` 保持不变。

## 调整内容

- 侧栏与主区改为网格布局，不再依赖固定侧栏宽度配合主区margin计算。
- CSS视口宽度≤1024px改顶部导航，≤480px导航两列；短屏桌面侧栏可滚动。
- 出题配置按可用空间排版，≤700px一列；题目卡片至少250px，≤480px单列。
- 答案输入框保持76px宽度，支持3位答案；不靠压缩输入框或裁切页面掩盖溢出。
- 预设、错题、结果卡片按可用宽度调整列数；文案、页脚和按钮允许换行。
- 时钟与打印控件独立排版，小窗口打印按钮换行；计时数字保持等宽。
- 使用系统字体栈、显式浅色控件与统一下拉框样式，保留原生下拉交互。
- 限定历史摘要选择器为直接子元素，避免内部「计时与判断规则」受到摘要布局影响。

依据：Flex/Grid子元素默认最小内容尺寸可能阻止收缩，显式min-width:0释放空间；操作系统的表单外观可由appearance控制。参考 [MDN min-width](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/min-width) 和 [MDN appearance](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/appearance)。

## 如何验收

打开 https://ortunate.github.io/SoftwareEngineering_2026/ ，完成或放弃未提交题单后刷新。Windows Chrome可按Ctrl+F5重新加载样式。不要为刷新清除浏览器存储，以免丢失记录。

重点按**浏览器窗口可用宽度**检查，不按显示器物理分辨率推断布局。Windows 125%/150%缩放、Chrome 125%/150%/200%缩放都会改变页面可用空间。

每种窗口至少打开：今日练习配置、100以内50题、提交结果、错题、成长记录展开详情、数据与帮助。检查最长算式如100减100和3位输入；可反复生成，或使用自然出现的长算式，不必修改实际数据。
